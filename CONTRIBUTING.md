# Contributing

Bug reports, accessibility notes, source corrections, and rights questions are welcome.

This repository is a curated edition of Shape of the World. It includes thirty worlds and the web runtime that runs them. The full collection lives at <https://shapeof.world>.

If you want to send copyrightable code or content, agree the scope with the maintainer first and complete the contributor agreement described in [CLA.md](./CLA.md) (individuals) or [CCLA.md](./CCLA.md) (organizations). A pull-request checkbox is not a substitute.

Please do not add worlds, app code, or tooling that is not already in this edition.
