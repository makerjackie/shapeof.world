# Contributing / 贡献说明

Issues are welcome: bugs, accessibility problems, wrong data or sources, rights
concerns, translation mistakes and ideas. The maintainer makes the fix.

Code and content pull requests are not accepted for now. The project is
dual-licensed (AGPL / CC BY-NC plus a separate commercial license), which
requires the project to hold the rights in everything it ships.

Opening an issue does not transfer copyright.

## 中文

欢迎提 issue：Bug、无障碍问题、数据或来源错误、授权问题、翻译错误和想法都可以，由维护者来改。

暂不接受代码和内容 PR。项目采用双授权（AGPL / CC BY-NC 加单独的商业许可），需要项目持有发布内容的全部权利。

提 issue 不涉及版权转让。
