# AI 到底改变了什么

约 3:18、1920×1080、30fps 的中文数据片，无旁白。

- **论点**：AI 来了四年：钱、芯片、电都变了天，你的工作还没有——除了第一份。
- **那一个发现**：
  - 22–25 岁的人，在最容易被 AI 替代的岗位上比 ChatGPT 发布时少了约 11%；在最不容易被替代的岗位上多了约 10%。缺口 19%。
  - 老员工没有这个缺口；变化来自少招新人，不是多裁。
  - 出处：Brynjolfsson、Chandar & Chen，2026-08，描述性证据。
- **主道具**：AI 时代线路图。从 2022-11-30 到今天的四条泳道，各画一条真实数据：
  - 钱：英伟达市值
  - 芯片：全球内存营收
  - 电：美国 PJM 电网容量价
  - 工作：美国失业率
  - 各泳道纵轴都从 0 起。三条线冲上天，工作那条几乎不动。
- **结尾**：四年正好是一届大学生；"它没有先换掉谁。它先换掉了起点。"然后片名翻成"世界的形状"。

## 配乐

《千年之后（氛围版）》，和乐府，取自 <https://music.01mvp.com/>，和 `films/ai-real-cost` 用的是同一首。音频不进 Git，渲染前先下载：

```bash
curl -L -o public/music.m4a https://music.01mvp.com/audio/qian-nian-zhi-hou-bv1xmn36aexp.m4a
```

拍点沿用 `films/ai-real-cost` 测得的网格：111.62 BPM，第一拍 0.487 s（`src/timing.ts`）。

全片从曲子开头放起，只剪一刀：

- 片中第 32 小节，从曲子第 32 小节跳回第 24 小节，把主段多放 8 小节（`MUSIC_EDIT`）。
- 主段四小节一循环。跳点前后两小节的色度相似度都是 1.000，能量一致；在跳点处做 2 帧等功率交叉淡化。

片中几个落点对应的曲子位置：

- 片名：主段进来（曲子第 8 小节）。
- 说句公道话：间奏（曲子 40–48）。
- 那一个发现：间奏后音乐回来的那一拍（曲子第 48 = 片中第 56 小节）。
- 升华：高潮段（曲子 64–76）。
- 品牌片尾：淡出段。

## 重新生成

```bash
npm ci
npm run studio                       # 预览，选 Film
npm run render                       # 成片 → out/ai-impact.mp4（CRF 20，AAC 192k）
node tools/covers.mjs                # 封面 → out/covers/cover-16x9.jpg、cover-3x4.jpg
node tools/stills.mjs out/s 0 3820   # 指定帧的审片截图（半分辨率）
node tools/readtime.mjs              # 读字审计（44 行）
python tools/sheet.py out/s out/sheets   # 2×2 拼审片图（需要 Pillow）
```

- 字体（Inter、Noto Sans SC、Noto Serif SC、JetBrains Mono，均为 SIL OFL 1.1）由 `@remotion/google-fonts` 在渲染时加载，需要联网。
- 地图用 Natural Earth 1:50m 国界（`world-atlas`，ISC，数据为公有领域）和美国人口普查局州界（`us-atlas`，ISC），由 `d3-geo` 投影。
- 标志 `public/mark-disc.png` 取自 `films/tower`，即 `public/assets/brand/kit/mark-512.png` 按圆形裁出透明边，球体本身没有改色。
