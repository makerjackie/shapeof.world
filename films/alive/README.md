# 活着是主线

约 2:10、1920×1080、30fps 的中文数据片，无旁白。比系列其他片子慢一档：温柔、留白多、数字少。

- **论点**：活着是主线，其他都是支线。
- **主道具**：一生约 4100 周的格子（79 年 × 52 周），一条暖色的主干线（活着）横穿过去，上学、工作、赚钱是从它身上长出来的支线，会长、会断，主干一直在。
- **那一个发现**：哈佛从 1938 年起跟踪 724 个人的一生，跟到老，最能预示健康和快乐的是关系，不是成就。
- **结尾**：格子重新亮起来，过去的不涂黑，未来的留白，落在"用自己的方式，过完一生，活着便是成功。"，片名翻成"世界的形状"。

按 `STYLE.md` 做：Remotion 管线、系列配色和字体、左上品牌角标、来源 → 制作 → 品牌的固定片尾。管线和工具照 `films/tower/` 复制。

- 用户的决定：`BRIEF.md`；定稿的结构：`PLAN.md`；调研：`research/`（带链接、每个数字标了已核实或未核实）。
- 剧本：`SCRIPT.md`（含制作前对一手来源的核对记录）。
- 发布文案和来源：`DESCRIPTION.md`。

## 配乐

原创，代码生成：`music/score.js` 用 Web Audio 的 OfflineAudioContext 合成，不用采样。

- **音色**：引擎和《高楼的形状》《房子的形状》是同一套（鼓、钢琴、风琴贝斯、铺底、音效和片尾音频标志），这部片弹得更轻：毛毡感的底鼓，前半段用边击代替拍手，加了八音盒式的铃声旋律。
- **和声**：D 大调，Dmaj9 – F#m7 – Bm9 – Gmaj9。
- **速度**：96 BPM，一小节 2.5 秒，第 0 小节从 0.5 秒开始。
- **段落**：和 `src/scenes.ts` 的小节表对齐：开场 0–5，片名 6–7，慢律动 8–22，回落 23–26，上扬 27，重进 28–33（那一个发现），高潮 34–43（升华），回扣 44–45（鼓退出），收尾 46–51（片尾，音频标志在第 49.5 小节）。

渲染后的 WAV 不进 Git。重新生成：

```bash
node tools/render-music.mjs          # → music/score-raw.wav、public/score.wav（约 −12 LUFS，真峰值 −1.5 dBTP）
python tools/spectrum.py public/score.wav src/audio.json   # 底部频谱条和背景脉动（要 numpy、scipy）
```

## 重新生成

```bash
npm ci
npm run studio                       # 预览，选 Film
npm run render                       # 成片 → out/alive.mp4
node tools/covers.mjs                # 封面 → out/covers/cover-16x9.jpg、cover-3x4.jpg
node tools/stills.mjs out/s 15 300   # 指定帧的审片截图（半分辨率）
node tools/readtime.mjs              # 读字审计
```

字体（Inter、Noto Sans SC、Noto Serif SC、JetBrains Mono，均为 SIL OFL 1.1）由 `@remotion/google-fonts` 在渲染时加载，需要联网。标志 `public/mark-disc.png` 和《高楼的形状》同一份。
