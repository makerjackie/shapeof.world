# 活着是主线

约 2:23（正文约 2:09 + 固定片尾）、1920×1080、30fps 的中文数据片，无旁白。比系列其他片子慢一档：温柔、留白多、数字少。

- **论点**：活着是主线，其他都是支线。
- **主道具**：一生约 4100 周的格子（79 年 × 52 周），一条暖色的主干线（活着）横穿过去，上学、工作、赚钱是从它身上长出来的支线，会长、会断，主干一直在。
- **那一个发现**：哈佛从 1938 年起跟踪 724 个人的一生，跟到老，最能预示健康和快乐的是关系，不是成就。
- **结尾**：格子重新亮起来，过去的不涂黑，未来的留白，落在"用自己的方式，过完一生，活着便是成功。"，片名翻成"世界的形状"。

## 配乐

《千年之后（氛围版）》，和乐府，3:01，取自 <https://music.01mvp.com/>，和《AI 的真实价格》同一首。音频不进 Git，渲染前先下载：

```bash
curl -L -o public/music.m4a https://music.01mvp.com/audio/qian-nian-zhi-hou-bv1xmn36aexp.m4a
```

拍点沿用 `films/ai-real-cost` 用 `tools/beats.py` 测得的：111.62 BPM，第一拍 0.487 s，相位漂移不超过 ±10 ms（`src/timing.ts`）。曲子段落：前奏 0–8，主段 8–40，间奏 40–48，主段 48–64，高潮 64–76，收尾 76 以后。

只在小节线上剪，跳的长度都是 8 小节（和弦一轮）的倍数，速度不变（`MUSIC_EDIT`）：片中第 32 小节从曲子第 32 跳到第 40（进间奏，第 31 和第 39 小节色度相似度 0.999），第 48 小节从第 56 跳到第 64（进高潮，0.997，和《AI 的真实价格》同一刀）。所以：前奏放结论、格子和问题；主段放片名和第 1、2 章；间奏放公道话和支线断开；重进那一拍是哈佛研究；升华在高潮；片尾在曲子自己的淡出上。频谱条和背景脉动按实际播放的位置取值（`musicFrame`）。

```bash
npx remotion ffmpeg -i public/music.m4a -ar 48000 out/music.wav
python tools/spectrum.py out/music.wav src/audio.json   # 要 numpy、scipy
```

## 结构

| 小节 | 场景 | 唯一的结论 |

| 0–2 | 结论 | 活着是主线，其他都是支线（第一帧就是整句；树上标着上学、工作等支线） |
| 2–5 | 一生 | 4108 格一周一周填满，格子上落下"79 岁 ≈ 4,100 周" |
| 5–8 | 问题 | 放大到一年（52 周）、一周（168 小时）：这 4100 个星期，都去哪了？ |

| 24–32 | 02 喜欢 | 喜欢的事盖上"打卡"变灰（128 项实验，有争议）；真喜欢的格子自己一路长下去（183 项研究） |
