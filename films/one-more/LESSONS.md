# 成片经验：《再来一局》（打游戏明知道该停，为什么停不下来？）

2026-10-26。这一页记两组经验：同一个题目，v2、v3 的开头"一般"，v4 的开头作者说"这个就好很多了，以后就按这种标准来"；以及全片从 v8（2:46）收到 v9（2:16）时，节奏和审片上学到的。

## 作者原话

- v2："这个看着没有令人上头的感觉""前面十几秒没有让我有看下去的冲动""整个画面我也觉得还是太简陋了一点"。
- v3："开头的 2~3 秒感觉还没有太吸引人""那个圆环的方式，挺无聊的呈现形式的"。
- v4："你这个就好很多了，以后就按这种标准来""一上来就是哦，失败，水晶被打倒，然后，失败，然后，又会弹出什么，就是这些东西都很形象""之前那个圆环，超级不形象，我鬼知道你那个圆环是什么""七日签到，每日任务，这个就很好，就是每个都是有令人印象深刻的点"。

## 失败的样子（v2、v3）

1. **用抽象符号讲具体的事。** 一圈圈圆环代表"还差一点的设计"，线框大脑，扁平图标。观众得先把符号翻译回自己的经验才看得懂，翻译不出来就记不住。这些是我脑子里的概念图，不是观众见过的东西。
2. **从铺垫开始。** v2 开头是一块几乎不动的手机、慢慢打出的字，再接 4 秒片名卡；v3 是九局连闪，形式新，但每一局都看不清，是"信息"不是"事件"。头 3 秒都没有情绪的峰值。
3. **从洞察出发找比喻，而不是从观众的经历出发找画面。** 先有"想要和喜欢是两套系统""套在一起的时间圈"，再给它们配图，于是画面服务概念，不服务观众。
4. **审片的标准错了。** 我检查的是字读不读得完、有没有重叠、真峰值，没检查"一个陌生人第一眼会不会想看下去、看完记住哪个画面"。技术上过关，观感上不过关。
5. **配乐为了"能用、能分析"而选。** 曲库里三首可商用的短循环曲按章节拼接，节拍测得很准，但没有情绪起伏，"看完没有任何感觉"。

## 成功的样子（v4）

1. **第一帧就是观众亲身经历过的最强一刻。** 团战推到对面水晶只剩 1%，团灭，"失败"。玩过的人身体先有反应（破防），然后才开始想。
2. **每个画面都是观众认得出的实物。** 失败的结算页、"再来一局"按钮、"匹配中…"、晋级赛、每日任务、战令经验、皮肤碎片、七日签到、好友开黑。不用解释，一眼就懂。
3. **每个点都带一根"刺"。** 1%、还差 1 颗星、还差 1 局、1880/2000、99/100、明天领大奖、差 1 人、凌晨 01:47。具体的数字和处境，比"还差一点的设计"这句概括有力得多。
4. **一个词贯穿全片。** "差一点"：开头的 1%、满屏的面板，后面剑桥的老虎机实验测的正是"差一点"。一部片只讲一件事。
5. **开头抛一个后面能被科学回答的具体问题。** "为什么差一点输掉，反而更想再来一局？"它是观众真问过自己的问题，答案就在实验里。
6. **用题目自己的语言讲。** 讲游戏，就用游戏的界面讲。观众熟悉，画面也自然热闹、鲜艳。
7. **形式本身就是内容。** 主段强拍开场，面板一张张卡着拍子弹出来，看的过程本身就"上头"。
8. **配乐用经过验证、有起伏的曲子**（《千年之后》）。

## 以后每部片都先过这几问

1. 第一帧是不是观众经历过的最强一刻？如果是铺垫、片名、空镜，就换。
2. 每个画面：不看字，观众能认出这是什么吗？认不出，就换成他见过的实物。
3. 每个点有没有一根刺：一个具体的数字、时间、处境？
4. 全片能不能用一个词说完？
5. 开头的问题，是不是观众真的问过自己的？
6. 审片时假装是陌生人：第 3 秒想不想继续看？看完记住了哪一个画面？

## 全片：从 v8 到 v9（节奏）

作者看完 v7 开头说"基本上差不多了"，要求补上"差一点就赢了 / 不甘心"，做完全片后自己审两三轮；又说"节奏可以稍微快一点……短视频时代的用户……不会愿意慢慢看"。

1. **快，先从配乐的结构上找时间，不从每句字上抠。** 《千年之后》第 31、39 小节色度相似度 0.999，跳过 32–39 一刀省下 8 小节（17 秒），接缝在强拍上听不出来。再按"读完就走"把每段排紧，全片 2:46 → 2:16，没有删掉任何一个论点。
2. **按"故事小节"计时，曲子剪辑交给一个脚本。** 所有画面和字写成 `S(故事小节)`，曲子怎么剪只在 `time.ts` 和 `music9.py` 两处；改结构时画面跟着走，不用一句句改秒数。
3. **打字速度也是节奏。** 每字 1.4 帧 → 1.0 帧，一句 20 字的话早 0.3 秒读完。
4. **一个情绪词要有自己的画面和停顿。** "差一点就赢了 / 不甘心"单独占满屏、大字，背景的战绩退后变暗；进实验前留半小节完全安静的黑场。快的片子更需要这种"刹车"。
5. **全片里最弱的一场，往往是"概念图"复发的地方。** 生活里远方的目标，第一版又画成了三根进度条——作者早就说过进度条不直观。改成和游戏弹窗反过来的卡片：游戏里只缺一块，生活里 96 格只填了 2 格，雾从右边吞过来。同一种画法正着用、反着用，比换一种新画法更好懂。
6. **审片看排版冲突，也看"字和主体抢地方"。** 半分辨率的总览图上，结尾左边的字压到了手机，"知道"的标签压在状态栏上；单看一帧不明显，排成一张一眼就看出来。
7. **冷读专抓两件事："说过头"和"替观众回答"。** v9 冷读（20 岁玩家、45 岁家长两种读法）抓出：一夜的条画成一路上升，等于说"差一点越多越想再来"，研究没这么说；"游戏里的差一点是真的 → 所以更放不下"中间缺一步，改成"是你自己打出来的"，正好接上实验里"自己动手选"那条线；"处处都有人替你安排好"是阴谋论口气，换成"可免费的那一杯，并不更好喝"，在家长也熟悉的东西上先演一次"想要不等于喜欢"；结尾拇指离开等于替观众答了题，改成悬着。逐条见 `SCRIPT.md`。
8. **黑场在短视频里是危险的。** 半小节的安静保留，但在黑里打出下一段的第一句，安静从"像是结束了"变成"接下来要揭晓"。
9. **渲之前对一遍两边的文件。** 第一次冷读改掉的"为什么差一点输掉"（意思反了），改在了 Windows 本地却没推到 Mac，v9 整片照旧渲了出来，直到看 1 fps 总览图才发现。现在开渲前对一遍所有源文件的 md5。
