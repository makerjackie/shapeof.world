# 再来一局 · 剧本 v1

2026-10-26。用户的决定见 `BRIEF.md`，出处见 `research/sources.md`。括号里是画面。

## 一句话

- **问题**（8 秒内问出）：已经不好玩了，为什么还停不下来？
- **那一个发现**（品牌金）：差一点就中，比差很远更难受，却更想再来一把。更难受，却更想要。
- **落句**：想要，可以被设计。喜欢，只有你自己知道。
- **主道具**：一个圆形的"再来一局"按钮。它先是结算画面上的按钮，再是星盘的圆心，再是钻进大脑的入口，最后变成品牌的球。
- **两种颜色**：想要 = 霓虹品红 `#ff4f9a`；喜欢 = 暖杏 `#ffb07a`。品牌金 `#ffd166` 只给那一个发现和落句。游戏界面用冷青 `#6fd6ff`。夜黑底。
- **转场语法**：穿过圆心。按钮 → 星盘 → 大脑 → 手机 → 按钮。
- **规格**：1920×1080，30 fps，约 2:56（含片尾）。无旁白。
