# 发布文案：打游戏明知道该停，为什么停不下来？

## 标题

**打游戏明知道该停，为什么停不下来？**

## 简介（抖音 / B 站）

凌晨 1:47，今晚第 9 局，其实早就不好玩了，拇指还是按下了"再来一局"。为什么？

如果只是因为好玩，不好玩了就该停了。让人停不下来的，藏在两个地方：游戏里，和你脑子里。

游戏里：一局十几分钟，差一颗星升段，每日任务还差一局，赛季还剩几天，好友在等你。每合上一个圈，总有一个更大的圈还开着口。匹配系统又会找和你差不多强的对手，每一局的输赢都在一半一半附近。

脑子里：科学家发现，大脑里管"想要"和管"喜欢"的是两套不同的系统，管"想要"的那一套大得多，也更容易被点燃。剑桥大学 2009 年的一个老虎机实验里，"差一点就中"比"差很远"更难受，却让人更想再来一把。

这种"还差一点"的设计，不只在游戏里。想要，可以被设计；喜欢，只有你自己知道。
