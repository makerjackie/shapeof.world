# 发布文案：打游戏明知道该停，为什么停不下来？

## 标题

**打游戏明知道该停，为什么停不下来？**

## 简介（抖音 / B 站）

水晶只剩 1%，团灭，失败。凌晨 1:47，明天 7:30 要起床，拇指还是按下了"再来一局"。为什么差一点就赢，反而更想再来？

2009 年，剑桥大学的一个实验发现：老虎机上"差一点就中"，比"差很远"更难受，却让人更想再来一把，而且只在自己动手选的时候才这样；大脑里平时为"赢"亮起的地方，也亮了。

大脑里，"想要"和"喜欢"是两套不同的系统，"差一点"更像是在点燃"想要"。老虎机的"差一点"是机器转出来的，游戏里的"差一点"是你自己打出来的；匹配又让输赢一半一半，"差一点"就会一直来。外卖满减、购物车、打卡、集点卡也一样：离免费那一杯越近，人买得越快，可免费的那一杯并不更好喝。

想要，可以被设计。喜欢，只有你自己知道。
