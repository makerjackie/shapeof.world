# 世界的形状 · 导演守则

**做片只看这一页。** 根目录的 [`STYLE.md`](../STYLE.md) 只管网站和片子共用的品牌：标志、颜色、字体、名字。品牌素材和声音清单见 [`brand/README.md`](brand/README.md)。

> 你是这部片的导演。片子没有旁白，观众只靠画面、字和音乐看懂一件事，并且愿意看到最后。

这一页分三层：**硬规则**每部片都必须做到；**原则**是方向，怎么做由导演定；**技术坑**是踩过的坑。别的都由导演自己判断。不要把这一页当清单逐条打勾：片子好不好看，只能靠自己完整看一遍来判断。

## 硬规则

1. **品牌露出。**
   - 左上角标从第一帧一直留到片尾卡之前：圆形的球加"世界的形状"。
   - 球只用圆形的那颗：[`public/assets/brand/kit/mark-disc.png`](../public/assets/brand/kit/mark-disc.png)。**绝不用带方形底的 `mark-*.png` 方块。**
   - 片尾卡：正中"世界的形状"（带圆形的球），下面一行"看见世界如何运行"，底部一行 MakerJackie。片尾卡前可以放一页信息来源。所有平台统一不放网址（抖音会限制站外导流），不放制作页。
2. **数字是真的。** 每个数字都追得到出处和年份，完整来源写进简介（不带链接）。推算、估算、换算的数字说"约"；预测说清是谁说的；公司自报的、描述性的证据不说成定论。
3. **素材有授权。** 音乐和音效用自己的曲库 <https://music.shapeof.world/>；地图用 OpenStreetMap 或 Natural Earth；照片用公有领域或 CC 授权的；字体用 OFL。
4. **交付规格。** 1920×1080，至少 30 fps；真峰值 ≤ −1 dBTP，响度约 −12 LUFS（在成片 MP4 上量）。
5. **发布文案。** 带 **#vibe知识大赏** 和 **@抖音科技**；热点题再加 **#vibe热点新知计划**。简介里不放网址。

## 原则

**判断顺序：故事 → 声音 → 节奏 → 画面。** 目标是"经典"：别人想到这个问题，就会回来看这一部。

**故事**

- 先有自己的一整套故事，再去找材料：立场、主角、情绪怎么走、那一个最想转给别人的发现、结尾那句话。调研为故事服务，查到的大部分东西不进片子。
- **一部片只讲一件事，讲透它**（用户 2026-10-26 定）。一条主线贯穿全片；支线可以有很多，但每条都要扣回主线，扣不回的就砍。素材再多，也挑最打动人、最切中观众痛点的那一个点，不把各家观点摆成清单。
- 讲到根上：不停在现象（"大家都这样"），要讲清"为什么会这样"，人是怎么一步步养成的。
- 少用"不是……而是……""你以为……其实……"这类翻转句式，直接把要说的话说出来。
- **文案向星球研究所靠拢**（用户 2026-10-25 定）：学他们的叙事节奏、文风、一路抛问题的方式和结尾往上抬的写法。他们片中的真人出镜段落不学，我们的片子没有真人。只学方法，不抄句子。他们靠旁白念，我们靠屏幕上的字，句子要更短。拆解笔记见 `films/XQ-STYLE.md`。
- 写给完全外行：短句，大白话，不用术语，英文公司名后面加一句中文说明。观众对数字不敏感，对自己的日子敏感，把数字换成时间、实物和人。
- 话不说过头，不站情绪立场，反证写进故事里。
- **不强塞“讲句公道话”的段落**，也不讲观众早就知道的常识（比如“大多数人不会上瘾”），只讨论现象本身（用户 2026-10-26：“有一些过分的客观是没有什么必要的”）。
- 结尾往上抬一层，落到观众自己身上，收在一句能被截图的话上。

**画面**

- **不做幻灯片。** "一行字配一张图，切到下一张"是最常见的失败。每一刻都要有东西在变，镜头要有理由地动。
- **字是画面的一部分**，没有固定的字幕位：字可以写在物件上、长在场景里、跟着镜头走，也可以整屏就是字。字要大，要读得完。
- 用一个连续的世界、一种转场语法把全片串起来，少用淡入淡出和硬切。至少一个只有这部片拍得出的招牌镜头。
- **画面不能简陋**（用户 2026-10-26）：《再来一局》v2 是深色底上的细线条矢量图（圆环、示意的大脑、条形图、扁平图标），作者：“整个画面我也觉得还是太简陋了一点”。要有质感：光、层次、细节、有内容的画面（比如手机里真的在打一局），不要只有线框和图标。
- 出处小字只在必要时上屏（预测、推算、公司自报、容易误读的数字），其余写进简介。

**节奏**

- **前 3 秒定生死**（用户 2026-10-26 定）：观众只给你两三秒。第 0 帧就要有一个让人想看下去的画面在动，不从空镜、慢推、黑场或一句铺垫开始；2 秒内让观众知道这部片要回答什么问题。能用画面抓人就别只靠字，字和画面都抓不住人就重做开头。
- **前 10 秒要有节奏、有事发生**（用户 2026-10-26）：《再来一局》v2 开头是一块几乎不动的手机、慢慢打出的字，再接 4 秒片名卡，前 20 秒只有一个画面，作者：“前面十几秒没有让我有看下去的冲动”。开头的画面要跟着拍子变，尽快进入第一个有意思的东西，不放长片名卡。
- 跟着音乐的段落和情绪走，不按固定的场景长度切：该快就快，该停就停；至少一次明显的加速和一段能喘口气的地方。
- 关键动作落在拍子上；卡点是落点准，不是每拍都切，也不是画面抖。
- 有用意的停留可以有，没用意的长停顿不要。

**声音**

- 关键动作可以配音效，音色和材质对得上；环境声不是必需的，导演看片子需要再加。
- 至少一处真正的安静，放在转折之前。
- 剪音乐只剪在小节线上，不改速度；跳接前确认听不出来。
- **配乐要么节奏鲜明、明快，要么用《千年之后》**（用户 2026-10-26）：《再来一局》v2 从曲库挑了三首约 90 秒的循环曲，一章一首来回换，作者：“这三种曲子真的是看完没有任何感觉”“看着没有令人上头的感觉”。不要几首曲子穿插拼接；曲库里的短循环曲没有起伏，撑不起一部片的情绪。

**封面和标题**

- 封面是在手机信息流里被看到的：一句大白话直接说题目（不用片子里的句子），配一张为封面专门画的主图。横版 1920×1080 和竖版 1080×1440 各一张，顶部是品牌条。缩到手机上一眼能读懂才算过。
- 标题 ≤ 20 字，和封面说同一件事。

**流程**

- 故事 → 剧本 → 一段带声音的动态样片（主线内部审）→ 全片 → 自己完整看一遍再交 → 用户看成片，给阶段意见。
- 剧本可以请另一个模型挑毛病；它给的数字要自己核。
- **作者的每条反馈都默认记下来，总结成经验**（用户 2026-10-26 要求）：能推广的写进这一页对应的段落（带日期和原话），只关于这部片的写进片子目录的 `BRIEF.md` / `LESSONS.md`。
- **每部片定稿后写一份 `LESSONS.md`**：这部片做对了什么、走了哪些弯路、有什么可以复用，附上作者的原话。能推广到所有片子的，补进下面的"成片经验"。

## 成片经验

做得好的片子，经验写在各自的 `LESSONS.md` 里，新片开工前先读。

- 《深圳写字楼空了四分之一，为什么还在盖？》：[`tower/LESSONS.md`](tower/LESSONS.md)。8 秒内问出观众的问题；一个主角把账算到底；数字换成观众有感觉的参照（足球场、国债）；答案分层、一层一个新意思；讲完小事一定要放大到宏观和城市的未来；升华回到开头的镜头、落到"你"身上；结构跟着音乐段落走；每稿外人冷读。
- **带动观众的情绪**（用户 2026-10-26，《熬夜》开头）：画面要有情绪的起伏，不要从头到尾一个速度。《熬夜》开头让观众亲眼看着一个循环越转越快：念头一句比一句重，手指越划越快，时钟越跳越远，紧张声越来越响，然后一刀切断、全场安静，再抛问题。用户原话："到后面你的情绪是有起伏的……逐渐刷的越来越快，然后节奏越来越好。"做法：先在真实场景里让观众代入，用加速、累积、对比把情绪推上去，在最高点停住，留一拍安静，再给答案。
- **一个画面只有一个主角**（同上）：亮的、动的、彩色的东西会抢走视线，旁边的字再大也会被忽略。要让字被读到，就在它出现时压暗其他东西，让它成为那一刻唯一的主角。
- **比喻要等观众需要它时才出场**：观众还在真实场景里时，突然换到抽象的比喻世界会让人出戏。先用真实场景把现象演完，到讲原理时再引入比喻。

## 技术坑

- **弹簧/回弹缓动会冲过头**：由进度算出来的数字要截断（`Math.min(1, p)`），否则会闪出错的数。
- **AAC 编码会抬高真峰值**：ffmpeg 自带的 `aac` 能冲过 2.7 dB，还不单调。母带从原始 WAV 做，用 Apple 的 `aac_at` 编码（做法见 `films/ai-impact/tools/tpmaster.py`）。
- **多个会话共用一个仓库**：在自己的 worktree 里干活；不要在主工作区 `git pull --rebase --autostash`，也不要 `git reset`。只提交自己的路径。
- **渲染排队**：Mac 上最多同时跑两个 `remotion render`，开渲前先 `pgrep -fl "remotion render"`。
- **共面会闪**：两个面贴在同一平面（房间盒子贴着楼板、隔墙贴着外墙）会 z-fighting，镜头一动就疯狂闪；几何上留 2 厘米以上的缝。细节（家具、窗框）按 fwidth 抗锯齿；灯光只做有意图的渐变，不要随时间随机开关或用 sin 闪电视。
- **WebGL 截图要等 GPU**：three.js 在 layout effect 里同步渲染完，再调 `gl.finish()`，否则偶尔截到半帧（做法见 `films/tower/src/world/engine.ts`）。
- **Overpass 公共服务器常 502、超时**：大片区的 OSM 建筑改用 Geofabrik 的分省 `.osm.pbf`，用 pyosmium 按范围裁（`films/tower/tools/pbf-nanshan.py`）。
- **WebGL 在 Mac 上要走 Metal**：headless Chrome 加 `--use-angle=metal`，否则会慢好几倍。
- **canvas 上画中文**之前，先用 `document.fonts.load()` 把字体载完。
- **曲库 CDN 拒绝 Python 默认的 User-Agent**（403），脚本下载时带一个 UA；目录里的 `bpm` 不准，以自己测的为准。
- 不用居中对齐的 SVG 文字；不在图表上用 CSS `filter`（多标签页渲染时会逐帧漂移）。
