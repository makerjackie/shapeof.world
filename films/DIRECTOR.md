# 世界的形状 · 导演守则

2026-10-23 定。**这是做片的最高规则**：和 [`../STYLE.md`](../STYLE.md)、[`METHOD.md`](METHOD.md) 冲突时，以本页为准，被替换的条目列在文末"和旧文件的关系"。品牌骨架、画风样帧、开头方案和声音清单见 [`brand/README.md`](brand/README.md)。

> **一句话：** 用一个外行也听得懂的故事，讲清世界的一个角落怎么运行。字少，画面具体，声音占一半。每部片换一种画风，品牌骨架不变。

规矩是为了让片子好看。哪条挡了路、有更好的做法，就破掉，在剧本里写一句为什么。

## 一、判断顺序

一部片按这个顺序评：**故事 → 声音 → 节奏 → 画面**。画面好看只是起点。

目标是"经典"：别人想到这个问题，会回来看这一部。一部研究扎实、但每屏都是一张图的数据汇编，不算。

## 二、故事

- **一个问题，一个发现，一个转折。** 开头抛出的问题在片中答完。"那一个发现"是最反直觉、最想转给别人的那个比较，放在后半段，落在音乐最大的一次重进上。
- **故事先于动画。** 一个好故事配最简单的动画，也有人看完。剧本只写文字：一个人或一个物件，遇到了什么，最后变成什么样。
- **写给完全外行。**
  - 不用术语、缩写和行业黑话；非用不可时，先用一句大白话说它是什么。
  - 英文公司名第一次出现时，后面加中文说明，例如 Chegg（美国作业辅导网站）、TrendForce（台湾市场研究机构）。
- **让人感觉到，而不是让人读数字。** 观众对数字不敏感，对自己的日子敏感：
  - 内存涨价，就拍装机的玩家买不起一套内存条。
  - 电网容量价，就拍电费单。
  - 预测，就翻译成"这对我意味着什么"：几年后买手机、找第一份工作会怎样。
  - 图表只在真帮得上忙时用，比如一只股票一天跌掉两成的那根线。
- **反证织进故事。** 不设"说句公道话"这类标签段落，反面的证据就是故事里的一拍："可是，失业率几乎没动。"
- **数字要准，话不说过头**（METHOD §3 照旧）。每个数都有出处和年份；预测写明是谁说的；描述性证据不说成因果。
- **一部片一个主道具或主隐喻**：开头立起来，结尾回扣。
- **结尾升华**（METHOD §7 照旧）：从数字走到人，收在一句能被截图的话上，不说教。
- **先找一两部标杆**：片子、片头、游戏、广告都行。写下要学的（构图、节奏、镜头语法、配乐结构）和不学的（角色、具体镜头、旋律、logo）。标杆比任何一条规矩都更能拉高质量。

## 三、前 2 秒和封面

2 秒留存最重要。**钩子和结论放在封面和标题上，不放在开头的静止画面里。**

- 第一帧就要有东西在动、有声音。不放片头 logo，也不把一整句结论定在屏上 3–5 秒。
- 前 2 秒只做一件事：画面上一个意外（价签翻牌、一摞硬币冲上天、一扇门砰地变窄），配一个响亮又好听的声音。
- 第 2–6 秒用一行字把这个意外接成故事，例如"一套内存条，一年多涨到了 449 美元。"
- 开场动画可以是任何东西，只要和片子的主道具在同一个世界里。
- 封面是一句大白话（≤ 15 字，不放数字）加一张专门为封面做的主图，版式按 `STYLE.md` 第二节。标题 ≤ 20 字，可以是问题。封面那句话不必是第一帧。

## 四、字

片子没有旁白，字就是旁白，所以字的出现方式固定下来，作为品牌骨架的一部分，每部片都一样。

| 字 | 样子 | 怎么出现 |
|---|---|---|
| 叙述句（讲故事的那一行） | 纸色 `#f1ecdf` 纸条，墨色 `#19231f` Noto Serif SC Bold 56–64 px，左边一道 8 px 墨色竖边；固定在左下（距左 96 px、距底 148 px） | 纸条从左划出（0.25 s），字逐个打出，每秒 12–15 字，第一个字落在拍上 |
| 关键词 | 同一行里，品牌金 `#ffd166` 荧光笔压在字的下半部 | 打完后的下一拍，从左往右刷上（0.3 s） |
| 数字 | Inter，等宽数字 | 在场景里跟着物件长出来；计数按落下的物件数走，不按时间；落定那一下有声音 |
| 场景里的标签（价签、读数、路牌） | 跟着当片的画风 | 由引线或物件带出来，跟着物件动 |
| 来源小字 | Noto Sans SC 19 px，60% 不透明，在纸条下方 | 和关键数字同屏；完整来源写进简介 |

- 一行 ≤ 14 字，一眼读完；一屏最多一条叙述句。宁可多分几行、多停一会，也不要一屏挤满。
- 读字时间：一行打完后，至少再停 0.6 s + 每字 0.15 s，最少 1.2 s（`films/house/tools/reading.mjs`）。
- 换行时，上一行整体淡出、上移 12 px（0.3 s），不滑出画面。
- 字不压主体；场景标签不进左下的字幕区。
- 文案写完读一遍，像人说的话吗？AI 腔的套话（"不仅……更……""值得注意的是""在……的背景下"）全部改成大白话。长文案或拿不准时，可以请 Gemini 4 帮着挑（见第九节），不是固定步骤。

## 五、画面

**骨架不变，画风每部换。**

- **骨架**每部一样：左上角标、字体、品牌色、字的出现方式、品牌声音、片尾卡。细则见 `brand/README.md`。
- **画风**每部自选：从 lemo-opuscar 的 59 种风格里挑，或在上一部的基础上改。哲学片可以用水墨，数据片可以是一个小小的 3D 世界。选法是同一时刻用 2–3 个方向各出一张风格帧，叠上骨架，给用户挑。
- 默认浅色。深色卡片、发光脉冲、满屏图表是旧片的毛病，不再是默认。
- **画面是真的世界**（METHOD §11）：讲一个地方，就上真地图；讲一个人，就画他真实的经历；讲一个东西，就画它真实的样子。
- **字配图**：讲历史人物时用真实照片（Wikimedia Commons 上公有领域或 CC 授权的，记下来源）；需要插画时，可以在 Mac 上用 Codex CLI 生成。生成的图只做插画，**不冒充真实的人、事和数据**。
- **一个招牌镜头**：只有这种画风拍得出的一下（一摞硬币冲破画框、移轴的清晰带一推落到一个人身上、整座小岛拉远变成一颗星球），放在情绪最高点。
- **每个镜头都有理由。** 全片至少用四种镜头运动（推、拉、摇、跟、升降、变焦）；关键时刻，主体占画面高度的三分之一以上。
- **转场在画风里完成**：一张纸翻过去、清晰带滑走、地块升起，全片用一种转场语法，少用默认的淡入淡出和硬切。
- 常见失败，逐条查：
  - 主体太小，或贴着画框边。
  - 字和底色太近，比如红字压红底。
  - 字盖住主体。
  - 一个笑点或意外闪得太快，没看懂。
  - 转场里有空帧。
  - 跟着主体的效果，在镜头动了以后没跟上。

## 六、节奏

- **音乐网格先行。** 动画之前，先测好曲子的 BPM、第一个强拍和段落（每 4 小节的能量），写出 cue map：每个画面变化、每个关键动作、每行字落在哪一拍。
- **每个画面变化落在强拍上**（小节的第一拍；次要的变化落在拍上），误差不超过 1 帧，用脚本核对。
- 但**不要每拍都切**，留出看的时间。全片要有快有慢：证据段快，转折前慢，至少一次明显的加速或减速，至少一处可以喘口气的长镜头。
- **永远不停在静止的结论上。** 大结论最多停 2 小节（约 4 秒）。停的时候画面还在动（镜头慢漂、物件余动、光在走），声音可以收。
- 高光每 20–30 秒一个，最强的放在后段（METHOD §6 照旧）。
- 卡点是转场和元素落在拍子上，不是整屏抖动。

## 七、声音

声音是半部片子，分三层：**环境声**（房间、风、机房）、**拟音**（跟着动作走）、**音乐**。

### 1. 每个动作都有声音

关键动作都配一个音效，音色和材质对得上：纸是纸声，金属是金属声，硬币是硬币声。

### 2. 安静

至少两处真正的安静，放在转折和情绪最高点之前。安静之后的第一个声音，要是全片最重要的声音之一。

### 3. 用声音转场

至少两次：下一场的声音提前进来（J-cut），或者上一场的声音拖过剪点（L-cut）。

### 4. 音乐

- **先用自己的曲库** <https://music.shapeof.world/>。机器可读的目录是 [`catalog.json`](https://music.shapeof.world/catalog.json)，先读里面的 `fields` 和 `taxonomy`；按 `styles`、`moods`、`energy`、`bpm` 筛，再自己测。
- **授权**：`rights.commercialUse = true` 的曲子（123 首）直接用；标 `legacy-unreviewed`、"使用权限待核对"的（384 首），发布前跟用户确认一次。音效和环境声都是 CC0。
- 《千年之后》用得太多，不再是默认。
- **音乐不必铺满全片。** 按"音乐、只有环境声、安静"三种状态来排。
- 曲子长度中位数约 88 秒，最长约 178 秒。2–3 分钟的片子，按下面三种办法之一排：
  1. **两首**：A 曲撑前半（铺垫和升级），在一处安静里换 B 曲，撑转折、发现和升华。不在乐句中间交叉淡化。
  2. **小节循环**：在 4 或 8 小节的循环点重复一段，先用色度相似度确认 ≥ 0.99（METHOD 技术坑照旧）。
  3. **用安静和环境声接**：音乐只出现在需要它的段落。
- 速度绝不改。剪辑只剪在小节线上，剪掉或重复的长度是乐句（4 或 8 小节）的倍数。
- **别默认钢琴加弦乐**，音色跟着画风走：小小的 3D 世界用马林巴、卡林巴、钟琴、木鱼；水墨用古筝、箫；档案片用钢琴、大提琴。
- "那一个发现"落在最大的一次重进上，升华在高潮段，片尾卡在收尾段。
- 响度在成片 MP4 上量：约 −12 LUFS，真峰值不超过 −1 dBTP。

### 5. 品牌声音（每部片都一样）

**音频标志**（2.6 秒，只用在片尾卡）：吸一口气，三个上行的木琴音（A4、E5、C#6，从左到右，像三笔画出一个圈），第三个音上"球"落地（110 Hz 的圆润低音），最后一道玻璃似的余光，对应球左上那道青色边光。草稿由 `brand/sound/make_sound.py` 生成，用户试听后定稿。

**品牌音效**，固定不换：

| 时刻 | 目录 id | 名字 |
|---|---|---|
| 一行字开始打出 | `sfx-ui-01` | 轻点 |
| 纸条字幕划入 | `sfx-foley-02` | 卡片滑动 |
| 数字落定 | `sfx-impact-06` | 陶瓷轻敲 |
| "那一个发现"亮起，金色荧光刷上 | `sfx-impact-05` | 玻璃轻碰 |

**世界音效**，下面是默认值，按当片的材质换成同类的：

| 时刻 | 默认 id | 名字 |
|---|---|---|
| 物件落地、堆叠 | `sfx-impact-01` | 木块敲击 |
| 计数的每一跳 | `sfx-mechanical-13` | 进纸机构 |
| 镜头内转场 | `sfx-transition-02` | 丝带掠过 |
| 安静之后的重拍 | `sfx-impact-08` | 低沉撞击 |

- 有音高的音效（数字落定、发现）可以移到曲子的调上（ffmpeg `asetrate` + `atempo`），别和音乐打架。
- 目录里音效的 `audioReview` 文字描述常和声音对不上，挑的时候要听，至少看一眼频谱。

## 八、片尾

- **片尾卡**：画面正中是"世界的形状"（带球的组合标志），底部一行 MakerJackie，配音频标志，约 3 秒。别的都不放：不要口号、网址、来源页、制作页。
- 来源全部写进视频简介（作者或机构《标题》，年份），不往平台贴链接。
- 底部的频谱条和进度条默认去掉。
- 升华和片尾合计约 30–40 秒，片尾卡落在音乐的收尾。

## 九、流程

| 步 | 做什么 | 交出什么 | 谁点头 |
|---|---|---|---|
| 1 选题 | 一个问题；给谁看；看完他会转给谁，配一句什么话 | 封面一句话（≤ 15 字）和标题（≤ 20 字） | |
| 2 故事和剧本 | 只写文字，写给完全外行：主角或主物件、那一个发现、反证放在哪一拍、预测换成"对我意味着什么"、高光时间表、逐镜头文案（每行 ≤ 14 字） | `SCRIPT.md` | |
| 3 风格帧 | 选 2–3 个画风方向，同一时刻各出一张，叠上品牌骨架 | `frames/*.jpg` | 用户选方向 |
| 4 音乐网格 | 选曲；测 BPM、强拍、段落；写 cue map 和声音设计表（每段的环境声、拟音、音乐状态） | `PLAN.md` 里的小节表 | |
| 5 15 秒动态样片 | 开头 15 秒，含前 2 秒钩子，带声音，按正式标准做 | `sample.mp4` | **用户确认后才做全片** |
| 6 全片 | 照样片定下的样子做完 | 成片 | |
| 7 审片 | 按第十节查 | 审片图、响度 | |
| 8 交付和发布 | 成片、横竖两张封面、发布文案 | `DESCRIPTION.md`、发布套件 | 用户 |

- 每部片最多改三版（METHOD §10 照旧）。
- **发布文案**：
  - 标题和简介用大白话，简介里写完整来源。
  - 每条都带 **#vibe知识大赏** 和 **@抖音科技**；热点题再加 **#vibe热点新知计划**。
  - 写完按第四节查一遍 AI 腔。长文案可以请 Gemini 4 审（可选）：在 Mac 上找个空目录，运行 `opencode run -m opencode-go/gemini-4-argon-contributor "<提示词>"`。它听不了音频；它给的数字和说法要自己再核。
- 发布后照 METHOD"流程"第 7 步上网站，把新学到的补进本页或 METHOD。

## 十、交片前自查

- 静音看前 2 秒：有东西在动吗？开声音看：声音抓人吗？
- 封面缩到 260 px 宽，还能一眼读懂吗？
- 有没有哪个结论静止超过 4 秒？
- 有没有哪行字超过 14 个字，或者没读完就没了？（读字审计）
- 每个画面变化都在强拍上吗？（拍点审计，误差 ≤ 1 帧）
- 每个关键动作都有声音吗？有两处真正的安静吗？
- 有没有出现"说句公道话"这类标签、来源页、制作页、频谱条、进度条？
- 每个英文公司名后面都有中文说明吗？
- 每个数字都说得出出处吗？有没有哪句说过头？预测都写了是谁说的吗？
- 每 10 秒一帧拼一张总览图，像幻灯片的地方打回；关键动作按 0.2 秒一帧拼成条看。
- 在成片 MP4 上量响度（约 −12 LUFS，≤ −1 dBTP），查黑帧，开声音完整看一遍。

## 十一、技术坑

METHOD"技术上踩过的坑"全部照旧：回弹缓动要截断、两行开场的读字时间、加长配乐只在循环点、响度在成片上量、多个会话共用仓库、渲染排队、地图授权。新加的：

- 在 Mac 上用 headless Chrome 渲 WebGL，要加 `--use-angle=metal`，否则会掉到软件渲染，慢好几倍（lemo-opuscar `core/render/browser.mjs` 的做法）。
- 在 canvas 上画中文（贴图里的招牌、价签）之前，先用 `document.fonts.load()` 把字体载完，否则会画成系统字体。
- 曲库的 CDN 会拒绝 Python 默认的 User-Agent（403），脚本下载时要带一个 UA，`curl/8` 就行。
- 曲库目录里的 `bpm` 是生成时的目标值，不是测出来的。例如《形状咬合》标 108，实测 110。以自己测的为准。
