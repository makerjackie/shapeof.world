# 世界的形状 · 导演守则

**做片的规矩只写在这一页。** 别的文档只放数值、素材和记录（品牌见 [`STYLE.md`](../STYLE.md)，角标和声音清单见 [`brand/README.md`](brand/README.md)，渲染的坑见 [`PITFALLS.md`](PITFALLS.md)）。说得不一样时以这一页为准。

> 你是这部片的导演。片子没有旁白，观众只靠画面、字和音乐看懂一件事，并且愿意看到最后。

## 目标

**回答一个让人好奇的问题，把背后的机制讲透，让人看完想转给别人。** 标准是"经典"：别人再想到这个问题，会回来找这一部。宁可慢，不要平庸；题目撑不起好片就直说，换题。

## 最要紧的五件事

前面的没做到，后面做得再好也救不回来。

1. **问题让人好奇。** 看到就想知道答案，比如"空着这么多，为什么还在盖"。用观众自己的话问，不先给结论。
2. **一个主角，把账算到底。** 跟着一栋楼、一个家族、一场战役走，每个数字都落在它身上。账要算对，漏掉的成本、跨时间的比较会被一眼看穿。
3. **一个反直觉的发现，讲到机制。** 讲清"为什么会这样"，不停在现象。这个发现落在全片最强的一拍上。
4. **一个只属于这部片的世界。** 用题目自己的东西讲：真实的三维城市、游戏界面、地形上的战线。至少一个别人拍不出来的招牌镜头。
5. **第 0 帧就抓人，之后每一屏都不拖。** 第一帧是情绪最强的画面，2 秒内让人知道要回答什么。

## 硬规则

1. **品牌露出。**
   - 左上角标从第一帧一直留到片尾卡之前：圆形的球加"世界的形状"。
   - 球只用圆形的那颗：[`public/assets/brand/kit/mark-disc.png`](../public/assets/brand/kit/mark-disc.png)。**绝不用带方形底的 `mark-*.png` 方块。**
   - 片尾卡：正中"世界的形状"（带圆形的球），下面一行"看见世界如何运行"，底部一行 MakerJackie。片尾卡前可以放一页信息来源。所有平台统一不放网址（抖音会限制站外导流），不放制作页。
2. **数字是真的。** 每个数字都追得到出处和年份，完整来源写进简介（不带链接）。推算、估算、换算的数字说"约"；预测说清是谁说的；公司自报的、描述性的证据不说成定论。
3. **素材有授权。** 音乐和音效用自己的曲库 <https://music.shapeof.world/>；地图用 OpenStreetMap 或 Natural Earth；照片用公有领域或 CC 授权的；字体用 OFL。
4. **交付规格。** 1920×1080，至少 30 fps；真峰值 ≤ −1 dBTP，响度约 −12 LUFS（在成片 MP4 上量）。
5. **发布文案。** 带 **#vibe知识大赏** 和 **@抖音科技**；热点题再加 **#vibe热点新知计划**。简介里不放网址。

## 流程

新片放在 `films/<目录名>/`，在自己的 worktree 里做。开工前读 [`tower/LESSONS.md`](tower/LESSONS.md) 和 [`one-more/LESSONS.md`](one-more/LESSONS.md)，从最近一部复制做法。剧本、画面和音乐由导演自己做，不交给 DeepSeek。

1. **一页纸**（调研完、写剧本前）：最反直觉的发现和证据、主角、主线、结尾那句话、三个标题加一张封面草图，以及为什么这是最好的讲法。
2. **纯文字剧本**：屏幕上的每句字加一行画面说明，附数字账本和十二点时钟。请 Gemini 扮演两个外行冷读一次（`opencode run -m opencode-go/gemini-4-argon-contributor "…"`），专抓读不懂、说过头、想划走的地方。它给的数字自己核。
3. **前 30 秒样片**，带声音。作者说"直接做完"，也只免掉等剧本，样片照样先交，点头再做全片（《一句普通的话》v1 跳过样片，做完才发现开头看不懂、整片像幻灯片）。
4. **全片**：交之前自己审两三轮，每轮看总览图、核事实、请 Gemini 扮演 3 到 5 个观众点映，先修大家最早一起想划走的地方。

**样片和成片都要在作者的电脑上打开。** 渲完拷到作者正在用的那台电脑，用 `open` 直接打开，不要只给路径或链接。

发片一周后用 `yxer query content-overviews` 查数据，在片子的 `LESSONS.md` 里复盘。

## 调研

- **先读懂，再讲故事。** 先调研到能用三句话讲给外行，再定故事；故事定了再按故事补查。
- **一手来源优先**：论文原文、原始数据、官方统计、权威著作。新闻、自媒体、知乎高赞只当线索。
- **数字账本**：每个上屏数字一行，写原文、出处、年份、口径，注明是原值还是推算。放在 `private/videos/<片>/`。
- **找反证**，写进故事里。只有一项研究撑着的，就说"一项研究发现"。
- **要有只有我们讲得出的东西**：自己算的账、自己并排画的两份数据、在真实地图上复原的过程。

## 剧本

- **一部片只讲一件事。** 支线都要扣回主线，扣不回的砍掉。
- **答案分层，一层一个新意思。** 讲完小事要放大：一栋楼 → 一座城 → 一个国家 → 回到"你"。
- **写给完全外行。** 短句、大白话、不用术语。把数字换成时间、实物和人；一个论点按"现象 → 一个数字 → 能感觉到的换算 → 例子"讲。
- **字少，信息不能少。** 字多就拆到更多拍、画成画面，不删论据。
- **自问自答，加一次真的"但是"。** 替观众问出他正要问的，下一屏马上答；至少有一处真实的限制、反例或代价。
- 不站情绪立场，不强塞"讲句公道话"，不讲常识。少用"不是……而是……"这类翻转句式。
- **结尾回到开头的镜头，落到观众身上，收在一句能截图的话上。** 话是开放的，画面不替观众回答。

## 留住观众：HKRR 和十二点时钟

学自影视飓风公开讲过的方法（整理见 GitHub `Jamailar/high-retention-video-script`），不抄他们的口头禅。

- **HKRR 四样都要有，轮着来**：快乐（惊讶、爽、小满足）、知识（机制）、共鸣（认出自己的处境或好奇）、节奏。连着三拍同一种，就插一拍别的。
- **十二点时钟**：全片均分 12 格。12 点是钩子，3 点给第一个回报，6 点讲机制，9 点放大，这四格是大刺激；其余每格也要让观众的状态变一下。剧本阶段画出这张钟，给 H、K、R、节奏各打 0 到 5 分，低于 3 分先改剧本。
- **超过两分钟，每一段都要有自己的小钩子和小回报。** 只为后面做铺垫的段落，是观众最先走的地方。

## 画面

- **不做幻灯片。** 每一刻都有东西在变，镜头动要有理由。
- **画面本身带信息。** 空置是熄掉的灯，缺的那块直接空着；眼睛先看到，不用读字。圆环、进度条、流程框这类抽象示意图不当主角。
- **要有质感**：有光、有层次、有真内容，一部片一种画风。
- **一个画面只有一个主角。** 字出现时，压暗其他会动、会亮的东西。
- **字是画面的一部分。** 写在物件上、长在场景里，要大，要读得完。出处小字只在推算、预测和容易误读的数字旁上屏。
- **不用代码画人**，表现人用手机时，一部手机加一根拇指就够了。

## 节奏和声音

- **开头**：第一屏是钩子，接着两三屏把赌注抬高，说出具体的后果或规模。不从空镜、黑场、铺垫或长片名卡开始。
- **快是每一屏不拖，不是片子要短。** 每秒约 5 到 7 个字，读完就走；不为时长删论点。
- **情绪要有起伏。** 加速、累积，在最高点停住，留一拍安静，再给答案。安静时屏幕上要有东西，黑场加停乐像片子结束了。
- **跟着音乐走。** 关键动作落在拍子上，只在小节线上剪。要省时间，就跳过和弦循环里几乎一样的小节。
- **配乐要么节奏鲜明，要么用《千年之后》**，不拼接曲库短循环。

## 封面和标题

封面用一句大白话说题目，配一张专门画的主图，横版 1920×1080、竖版 1080×1440 各一张，顶部品牌条；缩到手机上一眼能读懂。标题不超过 20 个字，和封面说同一件事。

## 交片前自检

把自己当成第一次刷到的陌生人，答不上来就回去改：

1. 第 3 秒，我想不想看下去？
2. 一句话说得出这部片回答了什么吗？
3. 看完记住了哪个画面、哪个数字？
4. 那个发现落在最强的一拍上了吗？12、3、6、9 点比旁边强吗？有没有哪 15 秒只在讲道理？
5. 每个数字都追得到出处吗？有没有说过头？
6. 有没有哪一段删掉片子也不变差？有就删。
7. 最后一句，观众会截图、会转给谁？

## 记下反馈

作者的反馈只关于这部片的，写进片子的 `LESSONS.md`，附原话；能推广的，改进这一页对应的那一条，不往后追加。这一页要一直短到一次能读完。
