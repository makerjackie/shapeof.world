# 世界的形状 · 导演守则

**做片只看这一页。** 以前的 `films/METHOD.md` 已经并进来并删掉；根目录的 [`STYLE.md`](../STYLE.md) 只管网站和片子共用的品牌：标志、颜色、字体、名字。品牌骨架的具体值、画风样帧和声音清单见 [`brand/README.md`](brand/README.md)。每做完一部片，把新学到的补进这一页。

> 你是做知识视频的编剧，要擅长把复杂的事情讲给完全不懂的人听。片子大约 2~3 分钟、横屏、没有旁白，观众只看画面上的字和配乐，所以每一句都要短，一看就懂。

这一页分两层：**硬规则**每部片都必须做到；**参考**是做过、验证过的默认做法和教训，导演可以改。

## 硬规则

1. **品牌露出。**
   - 左上角标从第一帧一直留到片尾卡之前：圆形的球加"世界的形状"。
   - 球只用圆形的那颗：[`public/assets/brand/kit/mark-disc.png`](../public/assets/brand/kit/mark-disc.png)，按圆裁好，四角透明。**绝不用带方形底的 `mark-*.png` 方块。**
   - 片尾卡：正中"世界的形状"（带圆形的球），底部一行 MakerJackie。
2. **写给完全外行**：每一句都要短，一看就懂。
3. **前 2 秒抓住人**：第一帧就在动、有声音；不放片头 logo，不把结论句定在屏上。
4. **英文公司名后面加中文说明**，例如 Chegg（美国作业辅导网站）。
5. **数字有出处。**
   - 屏幕上的每个数字都追得到出处和年份。
   - 推算、估算、换算出来的数字要标明（"约""推算""按某日汇率换算"）。
   - 预测要写明是谁说的。
6. **素材有授权。**
   - 音乐、音效、环境声用自己的曲库 <https://music.shapeof.world/>。
   - 地图用 OpenStreetMap（ODbL，要署名）或 Natural Earth 这类可商用的数据，不用高德、DataV。
   - 照片用公有领域或 CC 授权的，写明来源。
   - 字体用 OFL。
7. **先看样片再做全片**：做全片之前，先给用户看一段约 15 秒、带声音的动态样片，用户点头才往下做。
8. **交付规格**：成片至少 1080p，真峰值 ≤ −1 dBTP。
9. **发布文案**：带 **#vibe知识大赏** 和 **@抖音科技**；热点题再加 **#vibe热点新知计划**。

## 参考

下面的画风、动效、结构、节奏、字的样式、声音和配乐剪法，都是默认做法。每部片的导演在这里有最大的自由：只要片子更好，就不照做，在 `SCRIPT.md` 里写一句为什么。

**一句话：** 帮观众看见世界的一个角落是怎么运行的。看完至少得到一样：看懂了（知识），被触动了（共鸣），很意外或很好玩（快乐）；节奏决定他能不能看到最后。这是影视飓风说的 HKRR：快乐、知识、共鸣、节奏。

### 一、判断顺序

一部片按这个顺序评：**故事 → 声音 → 节奏 → 画面**。画面好看只是起点。

目标是"经典"：别人想到这个问题，就会回来看这一部。几行字加一个简单动画不够；研究扎实、但每屏都是一张图的数据汇编也不够。

### 二、故事

**一个问题，一个发现**

- 一部片只回答一个问题：开头提出，结尾答完，中间每一章都在推进这个答案。开头提的问题先回答，再展开别的，不开第二个悬念去打断第一个。
- 动手之前先找到"那一个发现"：最反直觉、最想转给别人的那个比较，写成一句话（"你付的利息，比盖这栋楼的钱还多"）。放在后半段做高潮，相关的数字同框放大，落在音乐最大的一次重进上。
- 结尾只用片子里出现过的数字来回答。
- 教训：《房子的形状》v3 开头问"剩下 67 万去哪了"，下一章却先讲"钱从哪来"；v1–v3 首付 30 万、盖楼 33 万、利息 37.6 万分在两章、隔了 35 秒，没放在一起比。《AI 的形状》v7 的结尾没回答开头的问题。

**故事先于动画**

- 一个好故事配最简单的动画，也有人看完。剧本只写文字：一个人或一个物件，遇到了什么，最后变成什么样。
- 一部片一个主道具或主隐喻：开头立起来，结尾回扣。全片用同一种计量单位（比如房子片里 1 块就是 1 万元）。
- 每一章都要完整：开头一句、证据、收尾一句。删东西之前，先看后面有没有用到它。教训：《AI 的形状》v7 的第 6 章只剩一个镜头；删掉欧洲以后，地图上的"欧洲 2"没有交代。
- 观点类、哲学类的题目（如《活着是主线》）按"写一篇有立场的文章"来做：一个人、一个故事、一个比喻撑起全片，数据只做点缀。研究堆得再整齐，没有立场也会无聊。
- 先找一两部标杆（片子、片头、游戏、广告都行），写下要学的（构图、节奏、镜头语法、配乐结构）和不学的（角色、具体镜头、旋律、logo）。标杆比任何一条规矩都更能拉高质量。

**让人感觉到**

- 不用术语、缩写和行业黑话，直接说结论：说"每年便宜 13 倍"，不说 GPQA。非用不可时，先用一句大白话说它是什么。
- 观众对数字不敏感，对自己的日子敏感。把数字换成时间、实物或人：要攒几年、几吨钢筋、少了多少工人；内存涨价就拍装机的人买不起一套内存条，电网容量价就拍电费单。
- 一屏只讲一件事、一个结论；先用简单的比喻讲清楚，再上数据。图表只在真帮得上忙时用，比如一只股票一天跌掉两成的那根线；增长用线性坐标，不用对数坐标（《AI 的形状》v3 的对数图一眼看上去像"没怎么变"）。
- 预测翻译成"这对我意味着什么"：几年后买手机、交电费、找第一份工作会怎样。
- **AI 题材**：先给全局（钱、芯片、电、工作这些线在全世界怎么变），再落到每个观众自己的日子上，最后收一个站得住的升华，不吓人也不鼓吹。

**话不说过头**

- 口径不同的数字写明口径；主因在前、次因在后；一个数字只揭晓一次；描述性证据不说成因果。
- 不用"真相、拆穿、石破天惊"这类词，不替观众做决定（不说该不该买房）。
- 不站情绪立场。讲到政府、银行、开发商拿走的钱，要接着说这些钱花到了哪里。
- 反证织进故事，不设"说句公道话"这类标签段落；反面的证据就是故事里的一拍："可是，失业率几乎没动。"
- 教训：AI 写的稿子说过头三处（"撑起了半个经济""父母辈的养老钱""晚 5 年省出一整套首付"）；《房子的形状》v6 只说"交给城市"，像在怪政府，v6.1 补上了土地钱的去向。

**钱用人民币**

- 中文版的价格用人民币，优先用国内真实零售价（京东、中关村在线、IT 之家、央视财经这类查得到的），写明型号、日期、来源。
- 国内找不到时按美元换算，数字前加"约"，来源小字里写明汇率和日期（如"按 2026-10-22 中间价 6.7195 换算"）。
- 字和数字放在语言层（`zh.json`、`en.json`），画面不写死：英文版用同一套画面，换成美元和英文。

**结尾升华**

- 不做购买推荐，也不复述要点：把主题往上抬一层，落到观众自己身上，回扣开场。
- 用片子自己的道具搭桥。《AI 的真实价格》在总结公式"单价 × 用量 ÷ 包月倍数"之后，补上"漏掉的最贵一项：你的时间"。
- 升华也要有数字撑着（解决一道编程题，87% 的成本是你检查、返工的时间）。
- 收在一句能被截图的话上，不说教："一套房，是两代人的半辈子"；"token 会越来越多，唯一不会变多的，是你的时间"。

### 三、开头、封面和标题

- 钩子和结论放在封面和标题上，不放在开头的静止画面里。
- 前 2 秒只做一件事：画面上一个意外（价签翻牌、一摞硬币冲上天、一扇门砰地变窄），配一个响亮又好听的声音。第 2–6 秒用一行字把这个意外接成故事。
- 开场动画可以是任何东西，只要和片子的主道具在同一个世界里。

**封面**是在信息流里被看到的：手机上 B 站一张卡片约 180 pt 宽，抖音主页一格约 130 pt 宽，封面会被缩到原图的十分之一左右。

- 每部片出两张，同一套版式：横版 1920×1080（B 站、YouTube、视频号横屏、网站），竖版 1080×1440（抖音主页、视频号）。
- 只放一句大白话，看完就知道这部片讲什么，≤ 15 字，不放数字（单独一个数字没有上下文）。横版分 2 行、竖版分 3 行，最小的字不小于 110 px（按 1080 宽算），关键词用主题色、语义色或品牌金。
- 封面不能只有字。每张都有一张专门为封面画的主图，占画面一半以上，只有一个焦点，不截片子里的帧；人脸、夸张的表情、放大的主道具最抓眼睛。字和图分开放，图不压字。
- 版式：顶部全宽品牌条（高约 6%，纸色底，左边"圆形的球 + 世界的形状"，右边口号"看见世界如何运行"），下面是那句话（Noto Sans SC Black）和主图。模板见 `films/ai-real-cost/src/CoverMock.tsx` 的 G 版。
- 交稿前把横版缩到 360 px 宽、竖版缩到 260 px 宽，还能一眼读懂才算过。

**标题** ≤ 20 字，可以是问题或反常识的话，和封面说的是同一件事。

### 四、字

现在的默认样式（细节见 `brand/README.md`）：

| 字 | 样子 | 怎么出现 |
|---|---|---|
| 叙述句 | 纸色 `#f1ecdf` 纸条，墨色 `#19231f` Noto Serif SC Bold | 字逐个打出，第一个字落在拍上 |
| 关键词 | 品牌金 `#ffd166` 荧光笔压在字的下半部 | 打完后的下一拍，从左往右刷上 |
| 数字 | Inter，等宽数字 | 在场景里跟着物件长出来；计数按落下的物件数走，不按时间 |
| 场景里的标签 | 跟着当片的画风 | 由引线或物件带出来，跟着物件动 |
| 来源小字 | Noto Sans SC 19 px，60% 不透明 | 和关键数字同屏；完整来源写进简介 |

- 一行 ≤ 14 字，一眼读完；一屏最多一条叙述句。
- 读字时间：一行打完后，至少再停 0.6 s + 每字 0.15 s，最少 1.2 s（`films/house/tools/reading.mjs`）。两行连读按总字数算。交片前跑读字审计。
- 字不压主体，场景标签不和叙述句挤在一起。
- 简体中文，短句，口语。AI 腔的套话（"不仅……更……""值得注意的是""在……的背景下"）全部改成大白话。长文案或拿不准时，可以请 Gemini 4 帮着挑（见第十节），不是固定步骤。
- 教训（2026-10-23 样片）：纸条字幕做得太小、放在左下角，读起来像幻灯片。字是片子的主角之一，要大、要在画面里有位置，打字的那几秒画面也要在动。

### 五、画面

- **骨架**每部一样：左上角标（硬规则第 1 条）、字体、品牌色、字的出现方式、品牌声音、片尾卡。
- **画风**按题目选，从 lemo-opuscar 的 59 种风格里挑，或在上一部的基础上改；哲学片可以整部换成水墨。选法：同一时刻用 2–3 个方向各出一张风格帧，叠上骨架，给用户挑。

**默认画风：精致的 2D（2026-10-23 用户定）**

- 默认是精致的 2D 动态图形和插画：真实的物件画成矢量插画（内存条、电表、工牌、一扇门），合适的地方用真实照片，图表只在真帮得上忙时用。
- 节奏回到以前几部片的叙事节奏：一行字、一个画面、一个动作，跟着拍子走，配合适的 2D 动画。
- 代码做的 3D 容易显得廉价，不用。
- 选型记录：
  - 2026-10-23 三张风格帧里，用户最喜欢"真物件 + 硬币堆"的读法：第一眼就是"真贵了"。
  - 按这个方向用 three.js 做的 16 秒样片被否（"好糟糕"，比旧的图表片还差）。问题出在：简单几何体像占位符；打字的约 6 秒里镜头几乎不动；字幕小、在左下角像幻灯片；前 2 秒没抓住人；左上角用了方块标志。
  - 用户随后决定整个放弃 3D。留下的是"把数字变成看得见的实物"（硬币堆、价签）这个读法，改用 2D 插画来画。
  - 教训：风格帧好看不等于动起来好看；每一秒都要有东西在变。

**画面是真的世界**

- 一屏一个结论，不是一屏一个数字。黑底上一个大数字、一根柱子、一个圆环是幻灯片，不是片子（《高楼的形状》v1 被打回的原因）。深色卡片、发光脉冲、满屏图表不是默认。
- 讲一个地方就上真地图（市 → 区 → 街 → 地块），讲一栋楼就画它真实的样子，讲一个人就画他真实的经历。调研里有的，尽量展开到画面上。
- 字配图：讲历史人物用真实照片；要插画时可以在 Mac 上用 Codex CLI 生成。生成的图只做插画，不冒充真实的人、事和数据。
- 角色：可以有代表双方的小角色（比如 Claude 太阳和 DeepSeek 鲸鱼），只在开场、对比和结尾出来做反应，不抢数据。
- 品牌色只用在骨架上；每部片可以再加一个主题色，用在主道具和封面关键词上。涨跌只用语义色：绿 = 便宜、好、省；红 = 贵、坏、多花，别处不用红绿。
- 背景默认暖而浅，在一片深色科技视频里跳出来；黑暗留给戏剧时刻（一段安静、夜里、一个坏消息）。

**镜头**

- **一个招牌镜头**：只有这种画风拍得出的一下，放在情绪最高点。
- **每个镜头都有理由。** 全片至少用四种镜头运动（推、拉、摇、跟、升降、变焦）；关键时刻，主体占画面高度的三分之一以上。图表和文字场景不一直慢推镜头。
- **转场在画风里完成**：一张纸翻过去、镜头推进一张插画、一条线长成下一张图，全片用一种转场语法，少用默认的淡入淡出和硬切。
- 常见失败，逐条查：主体太小或贴着画框边；字和底色太近（红字压红底）；字盖住主体；一个笑点或意外闪得太快没看懂；转场里有空帧；跟着主体的效果在镜头动了以后没跟上。

### 六、节奏

- **音乐网格先行。** 动画之前，先测好曲子的 BPM、第一个强拍和段落（每 4 小节的能量），写出 cue map：每个画面变化、每个关键动作、每行字落在哪一拍。
- **画面变化落在强拍上**（小节的第一拍；次要的变化落在拍上），误差不超过 1 帧，用脚本核对。一串连续的动作从拍上开始，最后一下落在强拍上。
- 但**不要每拍都切**，留出看的时间。全片要有快有慢：证据段快，转折前慢，至少一次明显的加速或减速，至少一处可以喘口气的长镜头。
- **永远不停在静止的结论上。** 大结论最多停 2 小节（约 4 秒），停的时候画面还在动（镜头漂、物件余动、光在走），声音可以收。
- 高光大约每 20–30 秒一个（一个意外、一组对比、一段好玩的动画），最强的放在后段，关键的证明卡在配乐最大的一次回落后重进。教训：《房子的形状》v3 的中段（贴息、养老金、50/70 年）变成了政策播报。
- 嫌长就删次要的字和整屏，不删好玩的镜头，不压缩单屏的时间。教训：《AI 的形状》v5 为了变短删掉了好玩的镜头，明显变差；《房子的形状》v3 里"花的比收的还多"只闪了半秒。
- 卡点是转场和元素落在拍子上，不是整屏抖动。

### 七、声音

声音是半部片子，分三层：**环境声**（房间、风、机房）、**拟音**（跟着动作走）、**音乐**。

- **每个动作都有声音**，音色和材质对得上：纸是纸声，金属是金属声，硬币是硬币声。连续的动作越密，单个声音越轻。
- **至少两处真正的安静**，放在转折和情绪最高点之前。安静之后的第一个声音，要是全片最重要的声音之一。
- **用声音转场**至少两次：下一场的声音提前进来（J-cut），或者上一场的声音拖过剪点（L-cut）。

**音乐**

- 曲库 <https://music.shapeof.world/> 的机器可读目录是 [`catalog.json`](https://music.shapeof.world/catalog.json)，先读里面的 `fields` 和 `taxonomy`；按 `styles`、`moods`、`energy`、`bpm` 筛，再自己测。优先用 `rights.commercialUse = true` 的曲子（123 首）；音效和环境声都是 CC0。
- 《千年之后》用得太多，不再是默认。
- 音乐不必铺满全片，按"音乐、只有环境声、安静"三种状态来排。
- 曲子长度中位数约 88 秒，最长约 178 秒。2–3 分钟的片子，按下面三种办法之一排：
  1. **两首**：A 曲撑前半（铺垫和升级），在一处安静里换 B 曲，撑转折、发现和升华。不在乐句中间交叉淡化。
  2. **小节循环**：只在 4 或 8 小节的循环点重复或跳接，先用色度相似度确认 ≥ 0.99，听不出来，也不挪动片名、发现、升华该落的小节。目录里 `loop.seamless = true` 的曲子可以直接循环。
  3. **用安静和环境声接**：音乐只出现在需要它的段落。
- 速度绝不改。剪辑只剪在小节线上，剪掉或重复的长度是乐句（4 或 8 小节）的倍数。
- 别默认钢琴加弦乐，音色跟着画风走：物件和数据类的 2D 片用马林巴、卡林巴、钟琴、木鱼；水墨用古筝、箫；档案片用钢琴、大提琴。
- "那一个发现"落在最大的一次重进上，升华在高潮段，片尾卡在收尾段。
- 响度在成片 MP4 上量（ffmpeg `ebur128=peak=true`），默认约 −12 LUFS。

**品牌声音**（清单和试听方法见 `brand/README.md`）

- 音频标志（2.6 秒，可选）：三个上行的木琴音画一个圈，"球"落地，一道玻璃余光，放在片尾卡上。
- 品牌音效：一行字开始打出 `sfx-ui-01`，纸条划入 `sfx-foley-02`，数字落定 `sfx-impact-06`，"那一个发现"亮起 `sfx-impact-05`。
- 世界音效按材质选：硬币 `sfx-impact-03`，物件落地 `sfx-impact-01`，计数和开关 `sfx-mechanical-13`，转场 `sfx-transition-02`，安静后的重拍 `sfx-impact-08`。
- 有音高的音效移到曲子的调上（ffmpeg `asetrate` + `atempo`），别和音乐打架。目录里音效的 `audioReview` 文字描述常和声音对不上，挑的时候要听，至少看一眼频谱。

### 八、片尾

- 片尾卡（硬规则第 1 条）用片子自己的画风做，约 3 秒，音频标志可选。别的都不放：不要口号、网址、来源页、制作页。
- `public/assets/brand/outro/` 里的成品片尾是旧样式，只给录屏这类没法自己做片尾的片子用。
- 来源全部写进视频简介（作者或机构《标题》，年份），不往平台贴链接；带链接的完整来源只放在发布套件和网站上。
- 底部的频谱条和进度条默认不要。
- 升华和片尾合计约 30–40 秒，片尾卡落在音乐的收尾。

### 九、规格和管线

- 1920×1080、30 fps、横屏，不做竖版剪辑。片长 2–3 分钟，由内容决定。
- 不露脸，默认不配音。题材需要旁白时：先定稿旁白再做画面，剪辑跟旁白的断句走，配乐在人声下压低约 10 dB，屏幕上仍保留关键的字和数字，静音看也能懂。
- 代码逐帧渲染，默认 Remotion（从 `films/ai-real-cost/src/` 复制 `kit.tsx`、`fx.tsx`、`timing.ts` 和 `tools/`）。`brand/samples/` 里的 three.js 样片是被否掉的 3D 方向，只作技术参考（拍点网格、音效事件表、混音脚本可以借用）。`house/`、`ai-shape/` 的 canvas 管线只维护旧片。
- 上传文件：H.264 CRF 20，AAC 192 kbps，faststart。
- 技术禁区：不用居中对齐的 SVG 文字；不在图表上用 CSS `filter`（多标签页渲染时会逐帧漂移）；交片前从成片 MP4 抽帧检查。

### 十、流程

| 步 | 做什么 | 交出什么 | 谁点头 |
|---|---|---|---|
| 1 选题 | 一个问题；给谁看；看完他会转给谁，配一句什么话 | 封面一句话和标题 | |
| 2 调研 | 数字和出处先落进文件，每条注明强度（一手、二手、自报、预测、推算） | `research/`、`data.ts` 或 `DESCRIPTION.md` | |
| 3 故事和剧本 | 只写文字，写给完全外行：主角或主物件、那一个发现、反证放在哪一拍、预测换成"对我意味着什么"、高光时间表、逐镜头文案；不照参考做的地方各写一句为什么 | `SCRIPT.md` | |
| 4 剧本评审 | 请另一个模型只看文字，挑结构和冲击力的毛病；它给的数字和说法要自己核对 | 修改后的 `SCRIPT.md` | |

| 7 动态样片 | 约 15 秒，含前 2 秒钩子，带声音，按正式标准做（硬规则第 7 条） | `sample.mp4` 和总览图 | **用户点头才做全片** |
| 8 全片 | 照样片定下的样子做完，跑读字审计和拍点审计 | 成片 | |
| 9 审片 | 按第十一节查 | 审片图、响度 | |

- 每部片最多改三版；三版以后还想改的，记下来放进下一部。
- 发布文案的标题和简介用大白话，简介里写完整来源（不带链接）。写完查一遍 AI 腔；长文案可以请 Gemini 4 审（可选）：在 Mac 上找个空目录，运行 `opencode run -m opencode-go/gemini-4-argon-contributor "<提示词>"`。它听不了音频；它给的数字和说法要自己再核。

### 十一、交片前自查

- 硬规则九条逐条过一遍。
- 静音看前 2 秒：有东西在动吗？开声音看：声音抓人吗？
- 封面缩到 260 px 宽，还能一眼读懂吗？
- 开头的问题在第几秒被回答？中间有没有岔开？"那一个发现"有没有同框放大？
- 有没有哪个结论静止超过 4 秒？有没有连续 30 秒没有高光的地方？
- 有没有哪行字没读完就没了？（读字审计）
- 每个画面变化都在拍上吗？（拍点审计）每个关键动作都有声音吗？有两处真正的安静吗？
- 有没有出现"说句公道话"这类标签、来源页、制作页、频谱条、进度条？
- 有没有哪句说过头？
- 结尾那句话，会有人截图吗？看完的人会转给谁？
- 每 10 秒一帧拼一张总览图，像幻灯片的地方打回；关键动作按 0.2 秒一帧拼成条看。单张截图常常落在回弹之后，看不出错的数。
- 在成片 MP4 上量响度和真峰值，查黑帧，开声音完整看一遍。

### 十二、技术坑

- **弹簧/回弹缓动会冲过头**：由进度算出来的数字要截断（`Math.min(1, p)`），否则会闪出错的数（7,755 而不是 7,350）。
- **两行的开场句按总字数留读字时间**：31 个字约 5.3 秒。
- **加长第三方配乐**：只在 4/8 小节的循环点重复或跳接，先用色度相似度确认（≥ 0.99）。
- **响度在成片 MP4 上量**：《千年之后》增益 0.84 时真峰值 −0.4 dBTP，0.75–0.76 落在约 −12.3 LUFS、−1.4 dBTP。
- **多个会话共用一个仓库**：在自己的 worktree 里干活；不要在主工作区 `git pull --rebase --autostash`，也不要 `git reset`。只提交自己的路径。
- **渲染排队**：Mac 一次只跑一个 `remotion render`，开渲前先 `pgrep -fl "remotion render"`。
- **WebGL 在 Mac 上要走 Metal**：headless Chrome 加 `--use-angle=metal`，否则掉到软件渲染，慢好几倍（lemo-opuscar `core/render/browser.mjs` 的做法）。
- **canvas 上画中文**（贴图里的招牌、价签）之前，先用 `document.fonts.load()` 把字体载完，否则会画成系统字体。
- **曲库 CDN 拒绝 Python 默认的 User-Agent**（403），脚本下载时带一个 UA，`curl/8` 就行。
- **曲库目录里的 `bpm` 是生成时的目标值**，不是测出来的，还常差一个八度（《形状咬合》标 108，实测 110）。以自己测的为准。
