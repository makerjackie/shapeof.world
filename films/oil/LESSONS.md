# 成片经验：《油价一百六十年》

2026-11-05—06，数据走势系列第 2 集（上一集《金价两百年》）。在金价片的引擎上分叉（`src/g/EngineO.tsx`），做了 13 版，v13 定稿。片子回答一个问题：同一桶油，谁说了算？答案是谁手里有多余的油（洛克菲勒 → 得州和七大公司 → OPEC → 交易所和沙特 → 页岩油和 OPEC+ → 一条海峡）。

## 作者原话（按时间）

- 结尾三句由作者从候选里挑：「一百六十多年，1 桶油 / 跌到过负数，也冲到过 145 美元」「谁手里有多余的油 / 谁就能定油价」「今天，它卡在一条海峡上 / 最窄处，只有 33 公里」。
- v7：底部的「1 盎司黄金 = N 桶油」"看着挺无聊的"，别再讲黄金；底部换别的内容。
- v8：
  - "第一眼……看不出这是一个关于石油的主题"。
  - 地图像被上面一层不透明的东西挡住了。
  - 地图是静态的，不会放大、不会聚焦产油国，事件也没标在地图上。
  - 图标"像是一个模板做出来的"。
- v9：
  - 底部纯黑很怪，"底部那一边的空白不要放重要的信息就好了"。
  - 用线条画的抽油机"好简单"，3 秒处的油桶很奇怪，地图不精致。
- v10：
  - 铜版画能不能动起来。
  - 地图里海和陆地"看起来没什么太大的差别"。
  - 大跌时要切到全局，"一直在局部视角的话，就会以为它都是小跌"。
  - 右上角可以往右挪，TikTok 的按钮在右下。
- v12：
  - 「油价到底是谁定的？」和「2020 年 1 桶油 −37，今年 113」这两句删掉，字太长。前五六秒给几个重大事件，跟着节拍震动。
  - 23 秒处地图为什么是灰的。
  - "地图标注国界真的是一件要命的事情……完全不敢在国内发出去……最好就是不要有国家的边界"，要在仓库里写清楚。
  - 想要更多重大事件和技术进步；战争要有战争的动画。
- v13：海报式快剪被否，"前面几秒还是要出现那个折线"，事件跟着折线出现，像人口片那样。片尾不要「下一集」。"可以的，没问题"，定稿。作者觉得没有中国人口片那么燃，可能是配乐的原因。

## 做对了的

- **开头：** 折线在一个固定窗口里从 1973 冲到 2026。线头每落到一个瞬间（禁运、海湾战争油井大火、145、−37.63、123.70、海峡封锁），插画就在点上弹出，下一拍数字砸下，画面震动、闪色。只有最新那个带大标签。到 −37.63 时线砸穿「0 美元」那条线。接着片名压在整条线上倒带。
- **一看就是石油：** 全片统一一种画风，Gemini 3 Pro Image 生成的「黑底金色铜版画」，加上曲线下面的原油色、新高时的井喷、暴跌时线头滴下的油滴。
- **让插画动起来：** 先生成一台完整的抽油机，再用图像编辑让模型把它拆成底座、横梁、曲柄三张，位置不变。代码里按曲柄、连杆、横梁的运动关系装起来，曲柄每小节转一圈。另外把原油田图里的抽油机抹掉，在原位置换上会动的。（这两把 key 都没有 Veo。）
- **地图是背景，不是另一层：**
  - 只画 Natural Earth 海岸线：深蓝海面上有刻线波纹，海岸外有几圈水线，陆地是带细点纹理的铜色。
  - 地图一直铺到画面底边，图表后面淡、下面实。
  - 镜头飞到每个事件的发生地，插上插画和地名牌。
  - 产油国只用亮点表示。
- **每类事件一个看得懂的动作：**
  - 战争：导弹飞入、爆炸、起火冒烟。
  - 发现油田：井喷。
  - 减产：管道阀门关上，油流停下；开仓放储备：阀门打开，油流出来。
  - 页岩油：剖面动画，竖着钻 → 拐弯横着钻 → 压裂 → 油出来了。
  - 霍尔木兹：油轮停住、变红，海峡上打叉。
- **大跌拉远：** 讲完一次大跌，镜头拉到几十年，用普通刻度，把那一段描红，左上角给出「−77%，5 个多月，从 145.29 跌到 33.87」。新高就拿历史最高来比。
- **观众自己的单位：** 顶部的「≈ 元/升」，负油价也照样换算。

## 弯路

- 用金价片的地板（「1 盎司黄金 = N 桶油」）讲石油：作者觉得无聊。
- 地图做成下面一层、上面盖着图表：像被挡住了。
- 只用线条画的图标和抽油机：显得像模板。
- 产油国按国家填色、描国界：大国被刷成一片灰。**国界本身就不能画**（敏感，国内发不出去）。
- 禁运前的黑白「老电影」效果：把地图也染灰了，作者觉得怪。
- 开头做成海报式快剪：作者要的是折线上的事件点名。
- 价格保留两位小数时 11.575 显示成 11.57：要按四舍五入取整。

  - 海岸线地图（`drawLand`）

- 封面：`CoverO.tsx`，三个比例加品牌条（OilCover169、OilCover43、OilCover34）。
