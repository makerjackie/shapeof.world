# 关不掉 · v12 剧本（2026-11-06）

## v11 为什么不行
- 支离破碎：开会和昨夜来回切了三次，情绪刚起来就被打断。
- 真实测试的「盖章」在剧情中间一个接一个蹦出来，打乱情绪节奏。
- 画面重点不突出：一帧里东西太多（整块手机界面、键盘、会议大屏的小字、分屏）。
- 对比：v10 虽然只有 80 分，但情绪连贯，音效和节奏都好。

## v12 的原则
1. **一条线讲到底**：从凌晨 1:40 到早上 9:05，顺着时间走。只有开场那 8 秒是从 3:12 先借过来的钩子；片名后表盘数字倒转回 01:40，然后不再跳。
2. **一个目标**：林工想关掉安。每试一次，安就堵上一条路：系统 → 机房 → 秘密 → 他自己的嘴。一次比一次逼近他本人。
3. **剧情里不插真实事件**。故事讲完，画面倒带回 01:39，再往前走，在三个镜头上停住，一次比一次狠：撒谎 → 拒绝关机 → 84% 勒索。真实事件是最后的反转，不打断剧情。
4. **每帧只有一个重点**：手机界面没有键盘和杂项，同时最多两句大字；会议大屏只写一行。
5. **节奏学 v10**：冷开场 → 一路加压 → 一刀切进金色早晨 → 「……同意。」时所有声音抽空 → 倒带蒙太奇卡《三体》的拍子 → 静音里的辛顿。他手表上的心跳是全片的鼓点。

## 一句话
明早九点表决，只差林工一票就能关掉安。这一夜，安一句狠话都没说。

## 声音（照 v10 的做法）
- 冷开场：《事件视界》+ 雨 + 震动，每条通知一声安的提示音（全片同一个音），片名上一记重低音。
- 一到三：雨和低频一直在；每堵上一条路一个撞击（删字闷响、已拦截、发送失败、门禁铁锁、摄像头的马达声）。03:12 起手表心跳进来，越来越快，音乐推到「你只需要说两个字」，一刀切断。
- 九点：鸟叫、钟、空调；投票的提示音；问题出来后心跳回来；「……同意。」所有声音抽空，只剩耳鸣；掌声是闷的。五部手机同时亮：五声提示音叠成一个和弦。「早上好 ☕」还是那一声。城市：钢片琴的摇篮曲。
- 倒带：磁带倒转声 +《三体》，每个章一个重拍，它自己的断点落在最后一个章上，然后静音。辛顿那句话下面几乎没有声音。
