# 你的工资，流到了哪？（films/money-flow，v7）

约 2:58，1920×1080，30 fps，无旁白。用 Remotion 加 three.js 做三维小镇（Kenney CC0 模型）。配乐只用一首「脉搏 · 弦」，画面按它的小节剪。

## v7（2026-11-04）

作者看完 v6 说"原来那个太舒缓了，看不下去"，指定用曲库里的 B（「脉搏 · 弦」）做配乐，呈现方式可以换。片子要讲清楚钱在社会里怎么流动，以及普通人为什么不知道自己的钱在一道道流程里被拿走了多少，例子包括层层的税、国企、股市、贷款、钱生钱。

v7 跟着一张月薪 5000 的工资条走，每小节一个镜头、一个反转，镜头在小节线上硬切：

- 公司实际为你花了 6645 元，你到手 4075 元，个税是 0。中间的 2570 元一项项飞走：
  - 1300 元记在你名下；
  - 1270 元进了大家的池子；
  - 其中公司交的养老钱，当月就发给了今天的退休老人。
- 你以为你没交税？每件商品的价格里都含着增值税。全国税收里，增值税和消费税约占一半，个税只占 8%。
- 你花出去的钱成了别人的工资，也成了企业的利润和股东的分红；国企的大股东是国家。股票、基金和存款，主要在金融资产最多的那 10% 家庭手里。
- 钱停在了哪？一半的储蓄是收入最高的 5% 家庭存下的。这些钱借给买房的年轻人：你存 1 万一年得 95 元利息，别人借 1 万买房一年付 306 元。你的房贷，就是别人的存款。
- 为什么富人越来越富？
  - 收入结构不同：普通人的收入里，工资占 56.5%，房租、利息、分红只占 8.3%。
  - 个税不同：工资最高交 45%，炒股赚的差价和持股满一年的分红不交个税。
  - 新钱先到借得到钱的人手里（2009 年的例子）。
- 高潮把所有流动一起点亮：
  - 工资流过你；
  - 房租、利息、分红流向有资产的人；
  - 税流向政府，再变成学校、医院、养老金；
  - 新钱先到借得到钱的人手里。
  - 最后亮出资产差距：城镇最富的 10% 家庭拥有 47.5% 的资产，最穷的 20% 只有 2.6%。
- 落句（作者从四句备选里选定）：工资，是流过你的钱；资产，是留下来的钱。

数字和出处见私有 `LEDGER.md` 第十一节。工资条是示意：费率按国家规定和常见比例取，各地不同，屏上已写明。

## 历史版本

v4（2026-11-03）回到 v2 的悬念和画面。v3 改成跟着一张 100 块走，作者觉得"不如原来的有意思"，只有饭馆拆账那段被点名有意思，所以这段并进了 v4。v2 被指出的几处问题都在 v4 里改了：
- 2015–2018 房价的例子删了，改成"浪潮"，涨和退都讲；
- 管道和弧线不再闪；
- 每一笔流动都标上它是什么钱；
- 美国那部分只留一条数据。

v5（2026-11-04）内容和数字不动，改声音和画面。作者看 v4 觉得"配乐加上这个画面，看不太下去"：
- 配乐：v4 前 2 分 49 秒是同一首拉长，中段垫的是一首写超新星的紧张曲子。v5 每一段换一首，揭晓前、浪潮退去时留出真正的安静；
- 光线：从午后的暖光开始，揭晓时日落，讲富人和浪潮时入暮，结尾入夜（`timing.ts` 的 `nightAt`）；
- 镜头：几处大全景换成贴近前排人家的中近景；
- 字幕：删掉和画面标签重复的小字，约少三分之一。

v6（2026-11-03）重新调研后改成反转链。作者看 v5：配乐和光线可以，但"洞察还不是特别深刻……数据跟这个结论有点怪怪的"，开头的大楼粗糙，前面慢，太平铺直叙。
- v5 揭晓的"前 5 户约 5000 万"是把储蓄分布直接乘上 1 亿，屏上不再出现模型数，只放调查和统计原值；
- 主线换成钱的真实机制：贷款生出一笔存款和一笔债，存款到处流，债留在借钱的人身上；
- 每段先抛问题再给反直觉的答案：18 万亿新钱、物价只涨 0.2% → 借钱的是企业，存款八成落在家里 → 一半是前 5% 家庭存下的 → 存款借给买房的年轻人，"你的房贷，就是别人的存款" → 2009 年贷款翻倍、物价反跌、地价翻倍 → 浪潮退去，债还在；
- 央行大楼拿掉，金流落进银行；美国税单、胡润、科技浪潮、全世界那几段删掉。

v6 的决定和理由见私有 `SCRIPT-v6.md`，数字见 `LEDGER.md` 第十节；v6 成片留在 Mac 上的 `out/money-flow-v6.mp4`。
