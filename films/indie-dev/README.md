# 独立开发者的形状

约 2:12、1920×1080、30fps 的中文数据片，无旁白（正片 2:00 + 固定片尾 12 秒）。

- **论点**：你刷到的独立开发者，是幸存者。AI 让做出一个东西几乎免费，供给爆炸，钱和注意力更往头部走；稀缺的是被看见、被信任。
- **那一个发现**：头部 1 个单人创业者赚的钱，等于普通人 61 个（四年前 34 个），落在配乐回落后重进的那一拍（第 25 小节）。
- **主道具**：一格一格带小脸的方块，每格是一个产品。全片都用它，最后 100 个方块按收入排队，排成一条长尾，就是"形状"。
- **结尾**："代码越来越便宜，信任越来越贵"；"做了很多产品没赚到钱，不是你一个人的失败，是这个游戏的形状"，片名翻成"世界的形状"。

- 方案：`PLAN.md`；调研：`research/`（带链接的原始笔记）。

## 配乐

原创，代码生成：`music/score.js` 用 Web Audio 的 OfflineAudioContext 合成，不用采样。

- **音色**：引擎和《高楼的形状》《房子的形状》是同一套（鼓、钢琴、风琴贝斯、铺底、音效），片尾的音频标志也是同一个。
- **和声**：A 小调。主段 Am9 – Fmaj9 – Cadd9 – G6，每段都从 Am 开始；升华段换成 F – G – Em7 – Am9。
- **速度**：120 BPM，一小节 2 秒，第 0 小节从 0.5 秒开始，所以第 0 帧是静止的整句结论，0.5 秒第一拍砸下来。
- **段落**：和 `src/scenes.ts` 的小节表对齐。片中的音效（`CUES`）按画面的拍子写在同一张表里。

渲染后的 WAV 不进 Git。重新生成：

```bash
node tools/render-music.mjs                                # → music/score-raw.wav、public/score.wav
python tools/spectrum.py public/score.wav src/audio.json   # 底部频谱条和背景脉动
python tools/beats.py <mono.wav> out/beats.json            # 复测拍点
```

## 重新生成

```bash
npm ci
npm run studio                          # 预览，选 Film
npm run render                          # 成片 → out/indie-dev.mp4
node tools/covers.mjs                   # 封面 → out/covers/cover-16x9.jpg、cover-4x3.jpg、cover-3x4.jpg
node tools/stills.mjs out/s 15 1515     # 指定帧的审片截图（半分辨率）
node tools/readtime.mjs                 # 读字审计
```

字体（Inter、Noto Sans SC、Noto Serif SC、JetBrains Mono，均为 SIL OFL 1.1）由 `@remotion/google-fonts` 在渲染时加载，需要联网。标志 `public/mark-disc.png` 是 `public/assets/brand/kit/mark-512.png` 按圆形裁出透明边，球体本身没有改色。
