# 富不过三代，是真的吗？· 作者的决定

做片的规矩看 `films/DIRECTOR.md`。选题来自作者 2026-10-31 的选题单第 1 条。

## 作者的要求

- 讲透"家族的财富和地位要几代才回到平均"。**中国和美国的数据都要**（选题单原话）。
- 看完一页纸后（2026-10-31）：
  - "美国也有很多那种大家族，有洛克菲勒……我也很好奇他们的情况。不只是讲中国。"
  - "中美两国都穿插对比吧。其他有一些特别知名的数据也行，不只是中美两国，只要是特别典型的例子都可以。"
  - "思考下整个剧本怎么来环环相扣……每隔一段时间就有个小高潮……让用户愿意持续看完这个视频。"

## 定下来的方向

- 一页纸：`private/videos/inherit/ONE-PAGER.md`。发现：钱散得快，位置散得慢；土改把钱拿走，孙辈的位置又回来了。
- 按作者意见改：开头用范德比尔特（散了）对洛克菲勒（还在）；中美交替；英格兰、日本、瑞典、佛罗伦萨各一拍作旁证；每段结尾抛出下一段要回答的问题，钟面上 12、3、6、9 点各放一个大刺激。

## 作者看开头样片的意见（2026-10-31）

- 样片：剧本 v2 开头第一名。印章"富不过三代"砸下 → 洛克菲勒肖像和七代金色家谱树 → 范德比尔特和 1894 年第五大道豪宅老照片，豪宅碎成块塌下，年份 1926→1947 → 两棵树并排，一棵金箔剥落成灰 → 问题。公有领域老照片做暖棕色调，金箔表示钱，灰表示钱没了。
- 作者："可以，这个很不错，可以完成整个片了，这个效果很好。"→ 按剧本 v2 做全片，沿用这套画风。

## 全片 v1 → v2（2026-10-31，自审和 Gemini 点映）

- v1 3:27 全片渲完，自己看总览图、核数字、查闪帧和配乐接缝。Gemini 扮演 4 个观众（45 岁做小生意的家长、21 岁文科生、33 岁程序员、60 岁退休教师）看字和时间线。
- 大家最早一起想走的点：0:44–1:08（四张名单卡连着日本、佛罗伦萨）。v2：名单卡只留名称和倍数，佛罗伦萨并成一句、用"600 年前"代替 1427。
- 其他改动：开头换算小字缩短，两棵树那句多给 1 秒；日本川柳改成"第三代把家卖了，'卖房'的告示却写得一手好字"；儿子一代加"因为出身"（论文：旧精英子女上学受限制）；大字改成"地分掉了。差距隔了一代，又长了回来。"；废奴一句改短；尺子一句补主语"一个家的位置要散完"；"拿不走的"先讲同住和婚姻，再讲"更信努力有用"，免得像在夸富人勤奋。
- 没采纳：Gemini 建议写"奴隶主家庭的财富跌去四分之三"（−75% 是全体南方富裕白人家庭，不是奴隶主）；"往上走 7.5%、7.3%"那句有观众觉得泄气，保留，这是片子里真的"但是"。
