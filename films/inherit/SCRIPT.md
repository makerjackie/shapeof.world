# 富不过三代，是真的吗？· 剧本 v2（纯文字）

2026-10-31。作者的决定见 `BRIEF.md`，数字账本在 `private/videos/inherit/LEDGER.md`。屏幕文字由 Gemini（gemini-4-argon）按事实表写，导演挑版本、核事实；v1 的 Gemini 冷读意见和改法记在本页末尾。

- **问题**：富不过三代，是真的吗？
- **发现**：钱确实留不过三代；一个家的位置，十代上下、约三百年才散完。把钱全拿走，孙辈的差距又长了回来。
- **主线**：钱散得快，位置散得慢。中美交替，日本、意大利各一拍作旁证。
- **一个世界**：一棵往下长的家谱树。钱是节点外面的一圈金箔，位置是节点里面的一团暖光；金箔两三代就剥落，暖光十代才慢慢暗下去。金榜、地契、福布斯榜单、清华新生名册、第五大道的豪宅都长在树上。
- **标题**：富不过三代，是真的吗？　**封面**：大字"富不过三代？"；一棵家谱树，上三代的金叶在飘落，往下第四到第十代的节点仍亮着暖光。
- **规格**：1920×1080，30 fps，约 3:15。配乐待定（《千年之后》或节奏鲜明的一首）。

### 落句：三个候选，按推荐排

1. **拿得走的，富不过三代；拿不走的，要走三百年。** 推荐：一句话收住全片的两个发现，"拿走"接土改和废奴，"三百年"接尺子。
2. **分得掉的，三代就散；分不掉的，十代还在。** 紧扣"分家"的解释，更冷静，但少了一点画面感。
3. **钱，三代就散；你往上走的一步，能留三百年。** 直接落到"你"，但有点像鼓励的话。

## v1 冷读（Gemini 扮演 45 岁家长、21 岁大学生）和这一版的改法

- 谚语 10 秒 6 条读不完 → 留 3 条，一屏一条；孟子挪到尺子那一拍。
- "钱拿走了，位置又回来了"太满，多挣 16% 撑不起 → "土改抹平的差距，隔了一代，又长了回来"。
- "奴隶主的儿子追上了同样出身的人"指代不明 → 写明对比的是"1860 年一样有钱、但没有奴隶的南方人家"（Gemini 建议写"北方富人"，与论文不符，没采用）。
- 江南 1973–89 年回到平均，中间隔着革命，不能当成自然消散 → 改成"两百年几乎没动 → 经过清亡、战乱和革命才回到平均 → 那把钱一下子拿光呢"，正好接到土改。
- "一部分来自位置，一部分来自运气"冒犯人 → 改用"分家"讲钱为什么散。
- 四个国家连报像报菜名 → 只留日本、佛罗伦萨。
- 基尼系数、"第 90 百分位"、中美 14.1% 对比这些读不懂的，删掉。
- 结尾用明朝进士安慰人像鸡汤 → 改成"位置传得慢，今天往上走的一步也会传很久"，明朝进士是"家谱的第一行"。
