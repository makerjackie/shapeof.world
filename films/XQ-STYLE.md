# 向星球研究所学什么

用户 2026-10-25 定：文案向星球研究所靠拢。2026-10-26 补充：他们的文案不一定都合我们的风格，但有可借鉴的地方。这一页只记方法，不抄句子。材料是用户整理的 14 篇结构分析（<https://research.01mvp.com/narrative-notes.md>，自动转写，未逐句听校）和我们自己转写的 5 篇。

他们靠旁白念，我们靠屏幕上的字：同样的方法，我们的句子要更短，一屏一两句。他们片中的真人出镜不学。

## 六个可以拿来用的方法

1. **开头把熟悉的东西变成一个反常的问题。** 都江堰："不建大坝，凭什么还能灌溉？凭什么能用两千年？"一个问题常常是两问叠在一起。观众本来就见过这个东西，所以问题是从他自己的经验里长出来的。
2. **一个答案留下新的难处，难处引出下一问。** 磁悬浮：摩擦 → 怎么浮起来 → 怎么稳 → 怎么往前走 → 怎么省电 → 发热。一路都是"解决了，可是……"，观众始终在追下一个问题，不会觉得在听讲。
3. **让观众一起当设计者。** 重庆、横琴：先把任务交给观众（"在这么点平地上，路往哪放？"），再一个个给出解法，每个解法又撞上新的约束。
4. **尺度一直在变。** 从一个零件、一粒沙，到一座桥、一座城、全国，再拉到几十年、几千年；讲到大的之后，一定再落回一个具体的人或物件。
5. **用一个事实去修正直觉。** 都江堰讲完精巧的设计后才揭开"年年岁修"，推翻"一次建成，永远有效"的直觉。最好的转折不是新信息，而是观众原来想错了。
6. **结尾回收开头，落到人和一代代的时间上。** 把开头的标签或画面重新拿回来，换一个意思；收在"大地和一代代人一起造成了它"这一类的话上。展望留着展望的语气，推测不说成定论。

## 句子

- 排比和重复推进："还不够"式的副歌，一层一层往上加。
- 问句多，但每个问句都要立刻有画面在回答。
- 数字少而准，落在一个具体的东西上（一座桥、一个人、一天）。

## 不学的

- 真人出镜、现场采访、花絮和品牌合作段落。
- 宏大的修辞替代因果：每一句"所以"后面都要有能追到的出处。
