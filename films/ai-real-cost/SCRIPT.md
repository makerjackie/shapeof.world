# AI 的真实价格 · 第 1 集 · 剧本 v10

> 系列《AI 的真实价格》第 1 集：聊天 AI。在已发布的 v5.1（"全球最聪明的 AI，比 DeepSeek 还便宜？"）上重做，照《深圳写字楼空了四分之一，为什么还在盖？》的做法：8 秒内问出观众自己会问的问题，跟着一笔账算到底，再放大到全世界，最后落回观众身上。
> 数据截至 2026 年 10 月 25 日，发布前全部重核。价格用美元（AI 订阅和 API 本来就按美元卖），国内会员价写人民币并注美元。

## 这一版和旧版有什么不同

1. **问题换了。** 旧版开头直接甩结论"Claude 比 DeepSeek 便宜"，后面全在给它举证，像广告。新版开头问一个普通人自己会问的问题：免费的 AI 到处都是，为什么有人每个月花 200 美元？"最聪明的反而最便宜"挪到中段当一次反转。
2. **"省 token"这条理由删了。** 最新数据里它站不住：DeepSeek V4.1 Flash 做一道题只要 $0.26，是全场最便宜的；Claude Opus 5.5 开到最强档反而用掉很多 token（2.6 亿，同档模型中位数的 3 倍）。所以按 API 算，DeepSeek 赢，片子老老实实这么说。反转只靠包月。
3. **结论收窄成站得住的那一句。** 不说"Claude 最便宜"，说"用满包月，最贵的 Claude，做一道题比 DeepSeek 还便宜"。ChatGPT 包月后同样很便宜，片子里照实画出来，Claude 只是五根柱子里的一根。
4. **"36 倍"补上前提。** 只有用满才是 36 倍。大多数人用不满（Anthropic：会碰到每周上限的不到 5%）。新增一章"健身卡"：免费额度是体验卡，包月是年卡，中转站是黄牛。
5. **Kimi 只列真实价格。** K3.1 Pro 智能榜第 4，但 API 输出 $10/百万 token，做一道题 $2.11，是 DeepSeek 的 8 倍；会员最高 ¥1,399/月，和 Claude Max 一个价，却不公开能用多少。
6. **升华从账单里长出来。** 旧版"唯一不会变多的是你的时间"是片尾喊的口号。新版"你的时间"是账单上的一行，放大看时 AI 那几行一年年变短，最后只剩你这一行。
7. **画面换成一个世界：夜晚的北太平洋。** 不转地球，平铺的夜景地图斜着看，镜头只推、拉、平移。中美两岸的城市灯光来自 NASA 卫星夜景；每个模型是一根光柱，立在它公司所在的城市，高度就是价格。全片同一组光柱变形三次，这是全片的"楼"。

## 画面世界

- **地图**：NASA Black Marble 2016 夜景（公有领域），以太平洋为中心，左边中国东部，右边美国西海岸。不画任何国界线、不标国名，只标城市。
- **五根光柱**（只选包月额度能算清或明确没有包月的旗舰）：
  - 旧金山：Claude Opus 5.5（Anthropic）、ChatGPT（GPT-6 Astra，OpenAI）
  - 北京：Kimi K3.1 Pro（月之暗面）、智谱 GLM-5.3
  - 杭州：DeepSeek V4.1 Flash
  - 同城的柱子并排站成一小排"天际线"，位置是示意。
- **柱子的三种状态**：标价（每百万 token 输出价）→ 做一道题（API）→ 做一道题（包月用满）。变矮时，原来的高度留一个淡淡的空壳，看得出掉了多少。
- **其他元素**：免费额度＝城市里闪起的小白点；中转站＝横跨太平洋的光弧；放大看＝年份计数，柱子一年年往下沉，数据中心的灯一片片亮起。
