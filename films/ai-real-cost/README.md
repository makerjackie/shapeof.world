# AI 的真实价格（v9）

2:26、1920×1080、30fps 的中文数据片，无旁白。论点：按单价，最聪明的 AI（Claude Opus 5.5）比 DeepSeek 贵 17 倍；可对包月用满的人，它反而最便宜。账要算三层：单价、用量、包月倍数，再加上最贵的一项，你检查、返工的时间。这个结论只属于今天：AI 每年便宜约 13 倍、用量暴涨，谁最便宜会换；最便宜的 AI，是最省你时间的那个。

## 配乐

《千年之后（氛围版）》，和乐府，3:01，取自 <https://music.01mvp.com/>（"抖音授权：收藏者声明"，可商用与否未单独核实）。音频不进 Git，渲染前下载：

```bash
curl -L -o public/music.m4a https://music.01mvp.com/audio/qian-nian-zhi-hou-bv1xmn36aexp.m4a
```

- 拍点：111.62 BPM，第一拍 0.512 s（`tools/beats.py`、`tools/downbeats.py`）。曲子段落：前奏 0–8，主段 8–40（8 小节一循环），间奏 40–48，主段 48–64，高潮 64–76，收尾 76–84。
- 只在小节线上剪，速度不变（`src/timing.ts` 的 `MUSIC_EDIT`）：片中 0–16 = 曲子 0–16；16–65 = 24–73；65– = 77–。跳点的色度相似度 1.000、0.999（`tools/chroma.py`）。这样"最聪明的，反而最便宜"落在曲子 48 小节（间奏后音乐回来），"可我们，用得更多"落在 64 小节（高潮）。
- 没有音效，和 v5.1 一样只有配乐。背景光团随曲子的低频起伏：`src/audio.json` 由 `tools/spectrum.py` 从曲子算出，按剪辑后的曲子位置取值。

```bash
npm ci
```
