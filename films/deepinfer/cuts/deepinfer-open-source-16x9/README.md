## 一句话

DeepSeek 这次开源的是一套叫 DeepInfer 的推理框架，不是新模型。模型决定 AI 有多聪明，推理框架决定有多少人用得起。

## 节奏怎么定的

- 没有旁白，所以每段只留一个主要信息，画面先给结构，再给结论。
- 大段文字至少停 2.5–4 秒；关键句（“是引擎”“开源 ≠ 免费”“让智能，用得起”）停 4 秒以上。
- 每 20–30 秒换一次画面类型：暗场文字 → 双卡对照 → 调度台 → 纸质 GitHub 卡 → 管线 → 六宫格 → 对比条 → 机房 → 双芯片 → 纸质清单 → 大字收尾。
- 音乐跟着段落走：钩子稀疏，调度段加压，开源处落下，中段保持，控制权处抽空，边界只剩脉冲，结尾收回来。

## 重新生成

```sh
# 1. 配乐与音效
python3 tools/score.py

# 2. 混音与响度
python3 tools/mix-silent.py

# 3. 逐帧渲染（1920×1080，60 fps）
node tools/render.mjs deepinfer-open-source-16x9 --w 1920 --h 1080

# 4. 合音轨
ffmpeg -i cuts/deepinfer-open-source-16x9/output/video-silent.mp4 \
  -i cuts/deepinfer-open-source-16x9/output/audio/mix-norm.wav \
  -map 0:v:0 -map 1:a:0 -c:v copy -c:a aac -b:a 192k \
  -af "volume=-0.6dB" -movflags +faststart -shortest \
  cuts/deepinfer-open-source-16x9/output/deepinfer-open-source-16x9.mp4
```

静帧：`node tools/still.mjs deepinfer-open-source-16x9 --w 1920 --h 1080 --at 12,50,100`
封面：`--cover --at 7.0`
