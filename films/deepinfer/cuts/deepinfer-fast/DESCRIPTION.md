## 正文（约 180 字）

大家都在等 DeepSeek 发新模型，它却把“后厨”开源了。

这次的主角是 DeepInfer：一套推理框架，负责把成千上万个请求排好队、塞进显卡、把回答稳定地吐出来。一起开源的还有 deepseek-recipe，负责把各家 API 的请求翻译成模型能读的格式。

它重要在哪？同样的卡、同样的电，能服务更多人，AI 才有机会更便宜；公司可以把它搬进自己的机房，数据不出门；它还支持英伟达和华为昇腾两条硬件路线。

但别误会：开源的是引擎，不是装好就能用的 AI。模型、缓存、负载均衡还得自己配。代码可以免费，算力不行。
