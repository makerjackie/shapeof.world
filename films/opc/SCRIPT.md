# 一人公司（OPC）的形状：剧本

v6，2026-10-30。1920×1080，30 fps，无旁白，3:05（92 小节）。数字的出处见 `research/RESEARCH.md`，屏幕上的字以 `src/film/Film.tsx` 为准。

## 一句话

AI 能替你干很多人的活；那条让人找到你、再回来找你的街，得自己修。

## v4 → v6（第四轮冷读、整片逐帧比对后改的）

v4 冷读：Gemini 62、DeepSeek 66（`research/coldread/`）。分数在几轮之间来回，很多意见轮与轮互相矛盾；站得住的三条照改：

1. **政策放回"手"那一边**：送工位、送算力降的是开张的成本，不是"街"。顺序改成：摆摊的人多了 → 不少地方还在帮人摆摊（政策卡）→ 担子交不出去 → 第二道天花板：街。后面"工位和算力，城市可以帮你省；回头客，只能自己攒"才前后呼应。
2. **"赚"改"收入"**：5,079 个项目的中位数和 Stripe 的倍数都是收入，不是利润。
3. **"让人找到你"先说动作**："开头那家：创始人边做边在网上公开记录每一步，/ 他本来就在创业圈做了好几年 / 那个建站工具，是靠口口相传传开的"。另把"按月租、按次买"写成"按月租个 AI、按次买个服务"；天亮段的字挪到左下，不再压着煎饼车的招牌。

整片渲两遍逐帧比对（v4 与 v5）发现两处会闪的地方：远处一扇窗隔帧亮灭、煎饼车的收款码图案逐帧变。原因见 `README.md` 的技术坑，已修。

## v2 → v3 → v4（第二、三轮冷读后改的）

v2 冷读：Gemini 62、DeepSeek（未打总分，挑出口径和衔接问题）；v3 冷读：Gemini 68、DeepSeek 56。原文在 `research/coldread/`。照改的：

1. **"为什么"分两层。** 34 倍到 61 倍是 2021→2025 的变化，那时网上早就没有远近了，拉大差距的是 AI：先讲"街没了"（电视为证），再讲"这几年 AI 又加了一把火"，用 Stripe 的数据（普通那家头半年收入一年少 23%，前 10% 多 19%），不用"客人没多那么多"这种没数据的话。
2. **"活交给 AI"和"客服：你、财务：你"打架** → 去掉角色标签，改成"活，可以交给 AI；担子，交不出去"，社保和《公司法》跟在后面，并点明"开的要是一人有限公司"。
3. **"于是，摆摊的人一下子多了"接在欠债后面，因果反了** → 顺序改成：一家公司要的人越来越少 → 于是摆摊的人多了 → 担子交不出去。两道天花板各加一个小标题"第一道天花板：手 / 第二道天花板：街"，把煎饼车的框架带到网上那半段。
4. **"街没了"说了两次** → 前面只说"网上，一个人也能卖给全世界的人"，转折处才说"可网上，也没有街"。
5. **答案从机制里长出来** → 加一层"街，原来替煎饼车做了两件事 / 网上没有街，这两件事，得自己做"，再讲"让人找到你""让来过的人再来"。
6. **结尾穿帮**：开头那家已经卖了 8000 万，不能在它的屏幕上"等待付款" → 结尾换成公司沉下去后留下的那张新桌子。
7. 大白话：开头"可在网上晒出真实收入的 5,079 个小生意里"；61 倍问"做得最好的那 10%，赚的是普通那家的几倍？"；电视"最红的那批演员，挣得更多了"（前 1% 占比翻倍放进小字）；答案大字不提 Base44，说"那个建站工具"；"算力券：政府发券，帮你付 AI 的钱"；小字补汇率和"中位数（排在正中间那家）"。
8. 没采纳的：删掉"担子"一段（知乎上合规、社保是读者最关心的两件事之一，留下并挪了位置）；删掉电视（它是"街没了 → 头部通吃"唯一有结果的证据，改成接在"为什么"第一层后面）；结尾给"可执行的方法"（片子落在一个开放的问题上，按导演守则不替观众回答）。

## v1 → v2（外人冷读后改的）

v1 的屏幕文字请 Gemini 4 和 DeepSeek V4 Pro 各扮 45 岁家长、21 岁大学生冷读（62 分、65 分，原文在 `research/coldread/`）。两边挑的问题高度一致，全部照改：

1. "一个人的公司"配小字"卖掉时团队 8 人"自相矛盾 → "一个人起步的公司"，并说清 Base44 是 AI 建站工具。
2. "街"的意思漂了三次（客流 / 竞争 / 熟客）→ 锁定为"来的人"：煎饼车的街给它路过的人，也护着它（附近的人就买它的）；网上没有街，人人都能卖给所有人，所有人也在抢同一批客人；赢的人自己修街，答案拆成两步：让人找到你（获客），让来过的人再来（回头）。
3. "一个人扛"插在"为什么头部通吃"和"赢的人多了什么"之间，打断推理 → 挪到政策热潮之后，当作降温："可公司一开，扛的都是你一个人"，再接"更难的是：街没了"。
4. 数字说得太专业 → "每 10 个新客人，下个月回来 3 个；普通的，不到 1 个"；"排在前 10% 的，赚的是排在正中间那家的几倍"；"一半，每月赚不到 1,100 块"；"留到第二年的老客人，花的钱多了近一半"。
5. 收住说过头的句子："各地开始抢一人公司"→"各地开始给一人公司送工位、送算力"；"一家公司缩成了一个人"→"一家公司要的人，越来越少"；"大家用的是同一个 AI"→"工具人人都能用"；"一人公司一点也不新"→"一个人做生意，其实一点也不新"（个体户不等于一人有限公司）。
6. 删掉"外包也行，可每回找人谈价太麻烦，不如雇进来"（大学生读者觉得反直觉）和"城市送的工位和算力，省的是'手'的钱"（硬套比喻）→"工位和算力，城市可以帮你省；回头客，只能自己攒"。
7. 电视那段加一句接口"这事，七十年前就发生过一次"，统计改成"收入挤进全美前 1% 的演员，比例翻了一倍"。
8. 片名不再写进营业执照的"名称"栏：执照上名称留空，片名单独大字。

   （退到摊位，再退到灯海，大多数灯暗下去）可在网上晒出真实收入的 5,079 个小生意里，/ 一半，每月收入不到 1,100 块。
   都是一个人做的生意，/ 差距为什么这么大？
2. **片名**：一人公司（OPC）的形状 / OPC：One Person Company，一个人开的公司（营业执照：名称空着，类型：有限责任公司（自然人独资），股东：1 人）。
3. **煎饼车**：一个人做生意，/ 其实一点也不新。标签：一辆车 · 一口锅 · 一张收款码；"收款到账"。全国 1.25 亿户个体工商户，/ 靠一个人或一家人撑着。它有两道天花板：/ 手：一口锅，一次只能摊一张 / 街：来买的，只有路过的人（镜头转成顺着街看）。可街也护着它：附近的人，就买它的 / 每天早上，都是那几张熟面孔（"老顾客 · 又来了"）。
4. **第一道天花板：手**：一家公司要很多人，/ 是因为活多。窗口标签：写代码 · 做设计 · 客服 · 记账 · 投广告 · 管机房。以前，每样活都得雇人干。现在，按月租个 AI、按次买个服务就行（标签翻成 AI 写代码、AI 出图、AI 客服、记账软件、投放平台、云服务，窗口一扇扇灭掉，楼沉下去，原地一张桌子）。一家公司要的人，越来越少。于是，摆摊的人一下子多了（街两边新摊位一个个亮起来；每月新上线的收费 App 2,000 → 14,700，2022 年 1 月 → 2026 年 1 月）。不少地方还在帮人摆摊：送工位、送算力（红横幅）。政策卡：工信部 2026 年 9 月 / 广东省发改委 2026 年 3 月 / 成都（征求意见稿）2026 年 3 月，附“算力券：政府发券，帮你付 AI 的钱”。活，可以交给 AI；/ 担子，交不出去。社保：公司那份、个人那份，都是你出。开的要是一人有限公司，公司欠了债，/ 你得自己证明：公司的钱和家里的钱，是分开的 / 证明不了，就要一起还。
5. **第二道天花板：街**：网上，一个人 / 也能卖给全世界的人（镜头从桌子垂直升起，灯一圈圈亮到天边）。
