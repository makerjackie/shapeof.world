## 本地运行

需要 Node.js 24 和 pnpm 10+。

```sh
pnpm install
pnpm dev
```

打开 `http://localhost:3000`。不需要 API Key。

```sh
pnpm check
```

该命令会做类型检查、测试和生产构建。
