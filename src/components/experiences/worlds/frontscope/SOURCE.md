# FrontScope native world

Source of truth: the FrontScope-Launch-Kit supplied by the project owner. Its original hash manifest and rights notes are retained in the launch kit and in Git history. The user confirmed GPT-6 Astra as the initial model on 2026-09-23; the catalog uses the registered `gpt-6` id.

`runtime.generated.js`, `stage.generated.html` and `styles/source.generated.css` are derived from the launch kit. Never edit these generated files.

The native renderer uses ShadowRoot isolation rather than an iframe. The website owns locale and immersive mode. ScopedWorld releases browser effects when leaving the route. The website integration reuses the same simulation and bilingual content as the original launch kit.
