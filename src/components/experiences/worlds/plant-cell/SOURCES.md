# 钻进一片菠菜叶 · 来源与模型边界

核对日期：2026-10-24。`plant-cell` 是连续尺度的解释性模型，不是同一片叶子的显微重建，也不是一个菠菜品种的联合生理拟合。下文把**实验测量**、**跨物种参照**和**显示参数**分开。未核实的范围不会包装成已测常数。

## 素材、代码与许可

- L0–L3 的叶片、组织、细胞器、纹理、颗粒和光束由本世界代码程序化生成，没有下载显微照片或第三方美术模型。
- L4–L5 的坐标来自 wwPDB/RCSB 的 mmCIF 和化学组分字典，数据许可为 **CC0 1.0**，包括 API 元数据。依据：[RCSB 使用政策](https://www.rcsb.org/pages/usage-policy)。结构作者和论文仍在下面逐一署名。
- 处理脚本为 `tools/build-molecules.mjs`。原始 mmCIF 缓存留在 `node_modules/.cache/plant-cell-pdb/`，产物在 `public/assets/plant-cell/molecules/`。不打包论文图版、全文、RCSB 网页文字或 Goodsell 插图；论文的事实引用不表示取得其图片的再分发许可。
- 高斯密度等值面使用仓库已有 Three.js 的 `MarchingCubes` 和 `SimplifyModifier`（Three.js，MIT）；原子显示使用已有共享 `SphereImpostorMaterial`，不修改共享代码。不引入新 npm 包。
- 未使用 OPM 的取向坐标或其他 OPM 数据，因此没有把未知 OPM 许可当作 PDB CC0。膜法线由存档跨膜螺旋的主方向估计，再用已知生物学标志决定正反。
- 本世界新增代码沿用仓库 AGPL-3.0；PDB 衍生坐标/网格和随附的原始事实元数据仍按 CC0 标明，不能被仓库原创内容许可覆盖。

## 光照、运输和日夜模型

- **净光合**采用非直角双曲线，初始量子效率 φ=0.05、总同化容量 25、曲率 θ=0.7、暗呼吸 Rd=1，通量单位 μmol m⁻² s⁻¹。净同化渐近值为 24，不能把总容量 25 写成净 Amax。Barratt 等 2020 的菠菜在 PPFD 2500 下净同化为 21.87±0.86，支持数量级；参数没有拟合该实验。净放氧按净同化 1:1 估算，省略光呼吸、循环电子流和其他电子受体。[doi:10.1093/aobpla/plaa067](https://doi.org/10.1093/aobpla/plaa067)
- **胞质环流**设为每秒约 1–5 μm。Peremyslov 等 2008 在拟南芥证明肌球蛋白 XI 参与线粒体、过氧化物酶体、高尔基体运输；本模型不是菠菜流体动力学。12 条贴壁路径与 3 条穿液泡胞质索、微小翻滚、布朗抖动、走停和近叶绿体停留均是形态/运动参照。×3600 用轨迹替代不可分辨的个体运动。[doi:10.1104/pp.107.113654](https://doi.org/10.1104/pp.107.113654)
- **叶绿体光迁移**独立于快速环流，参考速度 1–3 μm/min。Kadota 等 2009 的拟南芥 cp-actin 研究支持锚定和自主光迁移；Gotoh 等 2018 支持细胞形状限制弱蓝光聚光、强蓝光避光。白光 PPFD 约 100/400 的提示区间、180–800 的平滑权重和 24 个可进入顶部的成员，都是避免壁面重叠的显示模型，**不是菠菜实测阈值或群体比例**。[doi:10.1073/pnas.0906250106](https://doi.org/10.1073/pnas.0906250106)、[Gotoh 等原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5784166/)
- **气孔**按光照目标和 900 s 时间常数一阶响应；15 min 是 10–20 min 设计范围中的参照。未拟合气孔离子通道、ABA 或完整叶片水力学，气孔开度不反向限制本轮基础光合曲线。
- **淀粉**把正净同化碳的 25% 存入参考容量 100000 μmol C/m²，初值 35%。菠菜实验按日间增量/固定碳换算约 18.6%–28.6%，因此没有沿用设计中未核实的三到四成。显示百分比不是叶片干重百分比，容量不是生理上限。[doi:10.3390/plants12040804](https://doi.org/10.3390/plants12040804)
- **夜间消耗**借用拟南芥储量/预计黎明控制的近线性机制，目标消耗夜初的 95%。手动熄灯假定 12 h 夜晚；主动启用昼夜循环才按 06:00–18:00 正弦日照变化，时间加速不自行切灯。不模拟菠菜昼夜节律的分子网络。[doi:10.7554/eLife.00669](https://doi.org/10.7554/eLife.00669)
- **光学**：伪彩色、膜的边缘反射、指数光衰减、暖主光与冷补光、透明度、景深和颗粒用于辨认结构。照度到画面亮度的对数映射不是辐射传输测量；光片不等于完整体积散射。
- **水分扩展的数值边界**：设计的正常膨压 0.5–0.8 MPa、干旱体积减少 10%–20%、0.5 M NaCl 属于参考场景，尚未拟合同一菠菜样本的压力—体积曲线。干旱皱缩与浓溶液质壁分离必须分开；SoPIP2;1 开闭结构不等于一个完整水盐模型。

## 类囊体：尺寸、分区与电子流

Kirchhoff 等 2011 的 **拟南芥**叶片高压冷冻电镜给出暗适应与 500 μmol photons m⁻² s⁻¹、30 min 光处理后的重复距离分别 16.3±0.6 / 19.1±0.5 nm，腔宽约 4.7±0.8 / 9.2±0.6 nm。它们是指定条件下的跨物种参考，不能写成“菠菜强光必然到这个值”。模型在 0–500 PPFD 平滑插值，更高光不继续无限膨胀。[doi:10.1073/pnas.1104141109](https://doi.org/10.1073/pnas.1104141109)

几何严格满足 `重复间距 = 2 × 脂双层厚度 + 腔宽 + 基质侧层间隙`。为沿用 L3 连续交接，暗态采用 4.0 + 4.7 + 4.0 + 3.6=16.3 nm；光态采用 3.3 + 9.2 + 3.3 + 3.3=19.1 nm。**本模型的有效脂双层厚度为 3.3–4.0 nm**，并没有同时强行使用 4–5 nm 恒定膜厚和 3.6 nm 恒定间隙；那样光态将至少达到 20.8 nm，与指定重复间距冲突。膜头基颗粒、深色疏水芯和随机起伏是程序化示意，非脂质组或分子动力学轨迹。

Bussi 等 2019 显示类囊体网络同时含左右手螺旋。本世界保留两类连接的简化，修正“全部只有右手螺旋”的过度概括，未复刻一份断层扫描。[doi:10.1073/pnas.1905994116](https://doi.org/10.1073/pnas.1905994116)

电子链是 `水 → PSII → PQ → b6f → PC → PSI → Fd → FNR → NADPH` 的概念性有序动画。PC 位于腔，Fd/FNR 在基质，RuBisCO 在更外侧基质。亮点不是可见的真实电子，H⁺ 微光是浓度变化的代理，不按每个点等于一个溶液质子。未逐一守恒四个电子、氧分子、Q-cycle 的质子化状态、激发态寿命和 NADP(H) 池；不存在全膜电压/酸碱度求解。黑暗中停止光驱动通量、收窄腔隙和消退微光是稳态趋势，瞬态速度为显示参数。

## ATP 合酶：部件、方向、计数与时间

6FKF 的结构来自 Hahn 等 2018，F1 头为 α3β3γεδ，膜内 Fo 为 a、b、b′、c14；旋转部分是 **γ、ε、14 个 c 亚基**，α3β3、δ、b、b′、a 保持定子身份。注意“头在转”只是口语：整个 α3β3 头不会跟着转。使用单一沉积构象做刚体分组旋转，未计算真实弹性耦合。[doi:10.1126/science.aat4318](https://doi.org/10.1126/science.aat4318)

- **每圈计数**：c14 环的 14 个结合位点给出每圈 14 H⁺，三个 β 催化位点给出每圈 3 ATP，所以 14/3≈4.67 是理想紧耦合的**结构计量比**。c 环结构另见 Vollmar 等 2009 / 2W5J。它不包含跨膜运输 ATP、磷酸或其他代谢的额外成本，也不把溶液热力学测量的有效比值硬说成必为 4.67。
- **方向**：合成时从基质侧（F1 头上方，沿轴看向膜）观察，转子逆时针。Noji 等 1997 观察的是水解：从膜侧看逆时针；同时改变过程与视角才得到本世界的约定。Noji 原始实验为细菌分离 F1，不是菠菜活叶视频。[doi:10.1038/386299a0](https://doi.org/10.1038/386299a0)。反向机械旋转能驱动 ATP 合成的直接实验见 Itoh 等 2004。[doi:10.1038/nature02212](https://doi.org/10.1038/nature02212)
- **步进**：360°/14≈25.7° 是 c 环位点步长，三个释放事件按 120° 排列用于读懂计数。Hahn 的三种静态构象间实际角度约 103°、112°、145°，本世界的等分步进并非这三个构象的精确形变插值。
- **转速依据**：Junesch & Gräber 1985 在菠菜叶绿体、酸碱跃迁、约 150 ms 快速混合实验中报告最高约 400 ATP/CF1/s，按每圈 3 ATP 推导约 133 圈/s。模型取满量程 **100 圈/s 的数量级参照**，随参考总光合曲线缩放；没有把体外最大初速称作阳光下叶片内每台酶的直接测量。[doi:10.1016/0005-2728(85)90194-X](https://doi.org/10.1016/0005-2728(85)90194-X)。ΔpH/Δψ 依赖的原始实验另见 [Junesch & Gräber 1991](https://doi.org/10.1016/0014-5793(91)81447-G)。
- **黑暗停止**：无光时不再补充驱动质子梯度；γ 上氧化还原 β-hairpin/二硫键控制抑制浪费性的逆向 ATP 水解。模型用光照为零立即锁定，不模拟硫氧还蛋白、残余 pmf 或开关的反应延迟；“黑暗停转”不能解读成酶没有其他调控条件。依据 Hahn 2018。
- **时间标度**：电子链默认约 1/1000；马达另作显式局部慢放，正常显示约每圈 3–6 s，读数分别给参考转速与实际慢放倍数。人工选择更快时间时画面有速度上限，不能用画面转数反推整片叶子的总 ATP 产量。
- **原子外观**：只显示重原子，铜色标转子，象牙/暖沙标 α/β，钢灰标定子臂/a；是本世界伪彩色。1 nm 邻域原子数量生成的暗度是遮蔽代理，不是电子密度或静电势；原子球半径为常用范德华量级。膜、质子通道路径及 ADP/Pi/ATP 进出轨迹为机制示意，不是反应路径计算。

### 离线处理和取向的局限

1. 解析 `_atom_site` 和 `_entity.pdbx_description`，只取首个模型，去氢/氘与水，按沉积链/实体分类。未补建没有解析出的残基、侧链和氢；全原子在此明确指**已沉积的全部重原子**。
2. 按 `_pdbx_struct_assembly_gen` / `_pdbx_struct_oper_list` 扩出生物学装配。8RUC 的不对称单元只有 L4S4，需两套操作得到 L8S8。1RWT 的 assembly 1 是晶体中的多组三聚体（60 链），本世界取一个母链及配体加 C3 操作得到一个原生三聚体，不能误把全部晶体聚集体作为“一个 LHCII”。
3. 高斯密度 σ=0.29 nm，经 marching cubes 与边折叠减面得到表面；它是平滑的体积边界代理，**不是溶剂排除表面、实验电子密度图或分辨原子的边界**。远景亚基着色和表面简化会损失细节。坐标量化、三角面数、实际字节数在每项 JSON/清单中记录。
4. ATP 合酶以 c14 中心至 γ 链中心估计旋转轴；其他膜蛋白从长 α 螺旋的主方向估计膜法线，用 Mn、cyt f/Rieske、PsaC/D/E 标志定正反。测试保证标志位于正确半空间；这不等于已验证所有膜嵌入深度或柔性头部倾角。
5. 晶体/冷冻电镜各有采样条件；表面在膜中的随机排布是受生物学域约束的参照，不是一张断层图的坐标复刻。流动小分子、质子、电子和 ATP 轨迹均为可读性抽样。全原子模型不能作为能量最小化、结合计算或药物设计结构使用。

## 尚未被这个模型解决的问题

叶片解剖与生理采用多篇论文、多个物种和不同实验条件，没有建立同品种的参数一致性；完整光呼吸、离子与水盐守恒、膜电压、Calvin 循环、光损伤和修复、温度/CO₂ 反馈不在模型内。未核实的细胞尺寸继续保留为参照值。需要科学定量推断时，应回到上面的原始实验条件和数据，而不能从截图颜色、粒子个数或动画帧率倒推真实通量。

## 可复现状态与显示采样

- 只读网址参数：`scale` 是以米计的水平视野宽度的 log10（−0.58 至 −7.7）；`light` 为 0–2000 PPFD；`speed` 支持 0（暂停）、0.001、1、60、3600；`t` 为 0–24 小时的初始模拟时刻（循环取模），仅设置时钟，不伪造此前的光适应、淀粉积累或位移历史。昼夜循环仍需显式打开。
- `az` / `el` 以度给出当前尺度解剖坐标系中的镜头方位与俯仰，俯仰限制 −20° 至 70°；`capture=1` 隐藏界面。参数只在进入时读取，不同步改写网址。
- “顶面叶绿体”统计模型中心 y≥23 μm 的上端圆帽区域，不是光吸收截面的计数；总数始终 200。弱强光截图使用 ×60 实际运行后取帧，不把时钟参数误当作适应完成。
