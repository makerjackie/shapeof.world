# Car teardown

Original procedural FR sedan; no downloaded models or textures. Coordinates are front +X, up +Y, right +Z. All physical and construction dimensions live in `vehicle-spec.ts`; `SOURCES.md` distinguishes representative values from physical laws.

- `model.ts`: pure four-stroke kinematics, timing and transmission ratios. Angles are degrees; the visual crank advances by `rpm / slowdown`.
- `body-geometry.ts`, `engine-geometry.ts`, `gear-geometry.ts`: generated geometry. Body wheel-arch clipping is duplicated in the depth material. Cam profiles and valve followers use the same lift law.
- `Body.tsx`, `Wheels.tsx`, `Engine.tsx`, `Systems.tsx`: material and assembly components. Named parts use `userData.partId`, including ancestor groups for multi-mesh assemblies.
- `parts.ts`: bilingual registry and staggered system transforms. Counts represent registered parts/assemblies, not triangles or every fastener. Body panels currently share one loft.
- `Studio.tsx`: dark stage. An unlit floor disc fades into the clear colour `#07090b`, so the full-bleed canvas has no edge; an additive blurred reflection disc and contact shadows sit on it. Studio surfaces occupy render layer 2 (main camera only), excluded from reflection, contact-shadow capture and picking. `StudioReflection.tsx` and `StudioShadows.tsx` cache their blurred targets and refresh only while the camera, pose or assembly changes. Each offscreen pass restores the previous target and autoClear state. Paused crank scrubbing must invalidate both caches. The canvas fills the viewport under glass panels; `StageFraming` shifts the projection centre (view offset) into the free area (on phones it measures the band between the top card and the bottom drawer, centres and scales the subject into it, and eases back when the drawer is collapsed) and `ViewCamera` pulls each view back for the full-bleed canvas. Harness tubes use the light, faintly self-lit insulation in `harness-style.ts` so thin wires read on the dark stage. `ConceptBody` repaints the asset's main paint as light graphite so the body reads on the dark stage.
- `Scene.tsx`: camera, picking, system isolation and a 90-second idle turntable. The first interaction stops automatic rotation; reduced motion disables it. Keep the postprocessing subtree stable during slider updates. Tone mapping belongs in the composer, which disables the renderer's tone mapper.
- `brake-material.ts`: local guard for Three r183's anisotropic BRDF visibility denominator. Missing this guard produced non-finite HDR pixels at grazing angles; bloom spread them into black tiles or whole frames, despite no WebGL errors. A/B captures isolated the brake discs and verified the guard with all effects and mipmap bloom enabled. Do not work around this by removing AO/ghost systems or by modifying global Three shaders. Recheck after a Three upgrade.
- `Instruments.tsx`: projected SVG labels and 720-degree timing chart. Mobile controls scroll inside a collapsible drawer; every system also remains accessible through the system selector. Scrubbing must synchronously freeze `pausedRef` before assigning the shared angle: React DOM and r3f are separate roots, so state alone allows one extra frame.

Run `pnpm exec vitest run src/components/experiences/worlds/car-teardown` and `pnpm typecheck`. The tests include actual mesh raycasts for cylinder bores and inclined cam/follower contact, in addition to model invariants.

- `engine-castings.ts` and `engine-parts.ts`: physically open casting forms and 18 grouped engine parts. UI anchors and render groups read the same explosion offsets. Highlight materials are local clones; dispose them when groups unmount.
- `transmission-model.ts`, `transmission-geometry.ts`, `Transmission.tsx`: shared shift state, helical gears, moving sleeves/forks, full driveline and torque-path materials. Only the scene advances the clock; components and instruments read it.
- `EnginePartsUI.tsx` / `TransmissionInstruments.tsx`: local teardown list/cards and H-pattern selection. The drivetrain has close-up and full-path views.

- `steering-model.ts` / `SteeringMechanism.tsx`: ideal Ackermann geometry, four wheel paths and speeds, equal-angle Cardan joints, rack travel and the open differential. Positive steering is left (−Z); wheel spin is positive world +Z. The differential's local planet spin has the opposite sign to the reported speed difference because its local axes point outward.
- `brake-model.ts` / `BrakeMechanism.tsx`: pedal-to-pressure-to-torque chain and a floating single-piston caliper. Pad gaps are enlarged 20×; the 0.3-second pressure front uses screen time as an explanatory sequence, never as a hydraulic propagation model. Physical wheel deceleration uses the shared slowed clock.
- `suspension-model.ts` / `SuspensionMechanism.tsx`: fixed 1/480-second RK4 around loaded static equilibrium; front/rear quarter-car models produce heave and pitch. The road delay is exactly wheelbase / speed. Suspension geometry reads those states without its own simulation clock.
- `MechanismControls.tsx`: road-mechanism controls and shared time scale. New road views start at real time; engine/drivetrain retain their slower default. Unselected road experiments do not advance offscreen.
- `label-layout.ts`: projected-anchor left/right partition and vertical order, shared by system and engine-part annotations.
- New steering/brake/suspension IDs live in separate `*-parts.ts` registries, appended and ordered once by `parts.ts`. Detailed road-system part teardown is reserved for the next round.

- `pointer-events.ts`: orbit/dolly belongs to CameraControls, so drag/wheel events skip mesh picking. Hover/click retains a 4 mm line tolerance and only the closest hit per object. Three's default one-metre line tolerance generated tens of thousands of X-ray hits; R3F click bookkeeping then became quadratic on mouse release. Do not restore the default tolerance.
- `animation.tsx` / `visibility.ts`: hidden alternative views retain geometry but skip local frame callbacks, world-matrix recursion and picking. The scene's shared clocks continue independently.
- `repeated-geometry.ts`: bakes rigid repetitions into one mesh without simplifying vertices or normals. `assembly-framing.ts` caches bounded silhouette samples for camera fitting. `performance.test.ts` covers these invariants and event behavior.

- `RigidBatch.tsx` / `rigid-batch.ts`: only wrap fixed local transforms. Do not wrap moving links or shafts. Parent movement remains available; glass, custom shaders and teardown boundaries stay separate.

- `brake-render-geometry.ts`: four CPU-only front/rear rotor and caliper templates, copied into each scene instance. Do not share disposable instance buffers; entering brakes must not rebuild every casting edge. System highlight traversal runs only while a system is hovered and restores each shared material once.
- Retina canvas rendering is capped at DPR 1.5; narrow screens retain DPR 1.15. The composer uses 2× MSAA on both layouts to reduce Retina render-target bandwidth; AO remains at its existing quality. `RenderResolution` updates the budget on resize. Resizing also invalidates studio targets without disposing the reflector material prematurely.
