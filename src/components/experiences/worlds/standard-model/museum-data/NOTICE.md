# PDG property extract

Source: Particle Data Group, Review of Particle Physics 2024, [PDG API](https://pdgapi.lbl.gov/doc/restapi.html).

PDG data from the 2024 edition is licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The project software and original-content licenses do not relicense it.

Modifications: selected property records for the elementary particle museum, formatting and original Chinese explanations. Original responses are retained under `raw/`; the display extract is `snapshot.json`. Numeric limits, uncertainty and mass-scheme qualifications must be retained. Flavour neutrinos are not assigned single masses. The acquisition/extraction code and tool-version record are in `scripts/standard-model/`.
